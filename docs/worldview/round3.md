### 落とした案と理由

- **案4 おおせなか**: 文化をほぼ入れない前提の案で、今回の「もうちょい入れて」と逆向き。巨大な生き物の遠景モデルと動きが高く、「島が生き物」は既存作と比べられやすい。
- **案5 ともしび行**: 夕暮れの画面が「明るく柔らかく」から外れ、動く灯りは Windows の審査機での描画が重い。「灯りで世界を戻す」も既視感がある。良い部分（提灯の折り畳み、灯台の光が伸びるハブ）は **案B の提灯** と **案C の常夜灯** に移した。
- 混ぜた新案は作らなかった。3案はそれぞれ「陸を歩く旅」「つなぎ直す旅」「海を渡る旅」で、混ぜると冒険の気持ちがぼやける。文化の部品（凧・太鼓・提灯など）は案のあいだで貸し借りできる。

### どの案にも共通する、文化の扱いの約束

- **宗教の物を遊びの道具にしない**: 鳥居・しめ縄・神社や寺の建物・寺の鐘（梵鐘）・鈴・お札・灯籠流し（お盆に祖先を送る行事）は使わない。門は**木戸**（町の出入り口の木の戸）や桟橋の門にする。祭りは「島の祭り」として、提灯・太鼓・屋台・幟だけで見せる。
- **朱色を使わない**: 日本の物は朱（漆・欄干など）が多いが、赤は**禁止にだけ**使う決まりなので、漆は**黒漆と溜塗（茶色）**、布は藍・生成り・茶にする。
- **実在の地名・人名を世界に出さない**: 地名は日本の地名の作り方（〜峠・〜宿・〜浦・〜塚）をまねた**架空の名前**にする。実在の話は帳面の「ほんとうの話」1行にだけ書く。
- **画面で文化を解説しない**: 遊ぶ画面には物の名前（「羅盤」「とめ札」）だけ。由来や説明は、開かなくても遊べる帳面の中だけ。
- **ステレオタイプを避ける**: 忍者・侍・芸者・桜吹雪・富士山・「和風」の決まり文句の書体や効果音（琴のグリッサンド、鹿威しの「カコーン」）は使わない。
- **特定の作品の画風を指さない**: AI の指示は「寄木の箱」「和紙に墨の線」「藍の木綿」のように素材と形で書く（`docs/ai-usage.md`）。

## 案A　しろちず探検隊 —「地図に描けるのは、みんなで見た景色だけ。」

- **仮題**: 『しろちず探検隊』／英 *Blank Map Expedition*（別案: 『しろちず道中』）
- **一行**: 白い霧に包まれた群島を、探検隊が旅道具を貸し借りして歩いて測り、全員で頂に立って見た景色だけを、和紙の地図に描き足していく。
- **第2回からの変更**: 舞台を「無国籍の群島」から「**街道の文化が根づいた群島**」にした。島には一里塚・高札・道標・茶屋の跡があり、探検隊は草鞋と笠の旅姿。禁止を「とめ杭」から**高札の形の「とめ札」**に、信号を鐘から**呼び太鼓**にした。

### A-2. 仕組みの言い方

| 仕組み | 世界での言い方 |
|---|---|
| 器と能力 | 「どこへ行けるか」は体ではなく**針**が知っている。探検隊は寄木の**羅盤**に針を収めて持ち歩き、物に刺すとその物は針の向きへ動く。羅盤は手もとに残り、針だけが行き来する（ADR 0005 と同じ）。ジャンプ＝上の針、投げる＝遠くの針、登る＝崖の針、ダッシュ＝はやての針 |
| 禁止 | **とめ札**。高札の形の小さな札で、札のある物は、どんな針でもその向きへ動かない。島が昔から持っている決まりで、誰かの罰ではない。札ははがせないが付け替えられる。風呂敷（かばん）に入れても効く（「札は風呂敷の中でも読まれている」）。島の入口の大きな高札には、その島全体の決まりが記号で出る |
| 単発・繰り返し・信号 | **ひと刺し**（使ったら戻る）／**刺しっぱなし**（抜くまで）／**太鼓待ち**（呼び太鼓が聞こえる間だけ） |
| 生き物 | 島の住人**ミハラシ**（今の卵形の生き物）。頭の芽に**短冊**を下げていて、願いが絵で描いてある（見晴らしのいい所へ・巣へ帰りたい）。命令は聞かないが、針をもらえば自分の行きたい方へ使う |
| 全員でゴール | 頂の窪みに**標石と測量台**。探検隊の掟は「地図に描けるのは、隊の全員で見た景色だけ」。全員が立つと遠眼鏡で四方を見渡し、霧が晴れて地図にその島が描かれる |
| ハブの成長 | **はじまりの宿**（岬の小さな宿場）。最初は地図小屋と桟橋だけ。島を描くたびに霧が引き、茶屋・茅葺の家・一里塚・凧揚げの子ども（ミハラシ）・水車が増える。地図台の白いところが「まだ行っていない島」 |

標語の言い換え: **「地図は厳格に。道は自由に。」**

### A-3. 物語（サブ）

前置き（5行まで）:
1. 群島は白い霧に包まれていて、地図は白紙。
2. 霧は「まだ誰も見ていない」ということで、見た場所から晴れていく。
3. 若い探検隊が、はじまりの宿から島へ渡る。
4. 地図のいちばん端には、まだ何も描かれていない。
5. 宿の年寄りは、そこに「最初の探検隊」の野営があると言う。

伝え方: 地図が埋まること自体が物語。島には先の探検隊の跡（倒れた旗・古い一里塚・欠けた道標）。道標と高札は1行まで。ハブのミハラシが一言だけしゃべる（「きょうは 北が 晴れてるよ」程度。日替わり数種）。
最後の一場面: はしっこの頂に苔むした古い地図小屋。全員で立つと霧が全部晴れ、古い地図の余白に、今の隊の人数分の印が押してある。字幕は一行「余白は、次の誰かのために。」

### A-4. 学べるけれど教えない: 「道中帳」（任意）

- Esc メニューの中の帳面。**開かなくても遊べる**。最初は白紙で、島で道具や建物を見つけると1ページずつ埋まる。
- 1ページ＝絵1枚＋世界での名前＋「ほんとうの話」1行。例:
  - 羅盤の箱 —「寄木細工は、神奈川県の箱根で江戸時代の後期から作られている。」
  - ひと休みの塚 —「一里塚は、江戸時代に主な街道へ一里（約4km）ごとに築かれ、木が植えられた。」
  - とめ札 —「高札は、江戸時代に決まりを書いて、人の集まる場所に掲げた板の札。」
  - 地図 —「江戸時代の後期、海岸線を歩いて測った日本の地図が作られた（伊能忠敬らの測量）。」
  - 秘密箱 —「箱根の秘密箱は、決まった順に板をずらさないと開かない。」
- 帳面が埋まっても性能は変わらない（集める義務にしない）。

### A-7. 制作費・危険・今のモデルとの合い方

- **制作費: 小〜中**（3案でいちばん安い）。新規は針・とめ札・高札・道標・標石・地図台・茅葺の家。霧は Godot の高さ霧と遠景の板。太鼓の作り直しと効果音の採り直しが要る。
- **危険**: 地図を埋めるのが作業に見える（→ 地図は報酬だけ、収集の義務を作らない）／霧で見通しが悪くなる（→ 霧は遊ぶ範囲の外だけ）／「探検隊・地図」は広く使われる題材（→ 針で向きを貸す・全員で見た景色だけ描ける、で独自性）／街道の道具が「時代劇」に寄りすぎる（→ 刀・関所の役人・武家は出さない。旅人と道具だけ）。

### B-2. 仕組みの言い方

| 仕組み | 世界での言い方 |

### B-3. 物語（サブ）

前置き（5行まで）:
1. 島々は昔、太い大綱で一列に結ばれていた。
2. 綱は古くなってほどけ、島はばらばらに流れた。誰のせいでもない。
3. 結び港では、年に一度の祭りの支度が止まったまま。
4. 結び手たちは、海に垂れた綱の端をたどって島へ渡る。
5. いちばん古い綱の始まり「はじめの結び目」が、どこかにある。

伝え方: 沖へ島が寄ってくること、提灯と屋台が増えることが進み具合。島には古い結び目の跡・ほつれた綱の端。看板は1行。港のミハラシが一言（「提灯、またひとつ ふえたね」程度）。
最後の一場面: はじめの結び目で全員が引くと、すべての綱がハブまで張られ、櫓の太鼓が鳴って祭りの提灯が一斉に灯る（夕方の金色。この場面だけ）。

| 器と能力 | 船乗りは風を**扇**に詰めて持つ。扇で物をひとあおぎすると、その物は風の向きへ動く。扇は手もとに残り、風だけが出入りする。まえ・ひだり・うしろ・みぎ＝四方の風、ジャンプ＝吹き上げ、投げる＝吹き飛ばし、登る＝這い風（崖に沿って上る風）、ダッシュ＝追い風 |
| 禁止 | **錨札**。錨の付いた物は、その風を受けても動かない。「錨は風より強い」は船乗りなら誰でも知っている。外せないが付け替えられる。船箪笥（かばん）の中でも効く |
| 単発・繰り返し・信号 | **ひとあおぎ**（吹き終わると扇へ戻る）／**吹き続け**（畳むまで）／**鐘待ち**（船鐘が聞こえる間だけ） |
| 生き物 | ミハラシ（今の卵形の生き物）。磯や崖に住む。頭の芽に短冊。風をもらうと好きな方へ |
| 全員でゴール | 「**船は全員そろうまで出ない**」。島の頂の**日和山**で全員が方角石のまわりに立ち、風を読むと、かぜまち丸が迎えに来る |
| ハブの成長 | **風待ちの港**と**かぜまち丸**。最初は小舟一艘と船宿一軒。島を渡るたびに、船に甲板・帆柱・屋形・帆の継ぎ当てが足され、港に常夜灯の光が遠く伸び、船宿・凧揚げ・市の店が増える。港の暦の板が進む |

標語: そのまま「ルールは厳格に。解法は自由に。」、または **「錨は厳格に。航路は自由に。」**

### C-3. 物語（サブ）

前置き（5行まで）:
1. 群島の港は、どこも風待ちの港。
2. 船乗りは扇に風を詰め、港から港へ島をめぐる。
3. かぜまち丸は、まだ帆の小さな新しい船。
4. 沖のどこかに、すべての風が生まれる「風のみなもと」がある。
5. 着いた船は、まだない。

伝え方: 船が育つことが物語。島には古い船の板・錨・方角石。看板は1行（「ここから 錨」）。船宿のミハラシが一言（「きょうは 追い風」程度）。
最後の一場面: 風のみなもとの日和山で全員が風を読むと、帆に十二の継ぎ当てがそろったかぜまち丸が凪の向こうへ出る。港の常夜灯がすべて灯って見送る。

### C-4. 学べるけれど教えない: 「日和見帳」（任意）

- 例:
  - 扇 —「折り畳む扇は、日本で生まれたとされる。」
  - かぜまち丸 —「江戸時代の大きな木造の帆船（弁才船）は、大きな一枚の帆で走った。」

## 2. 推奨: 案A「しろちず探検隊」

1. **冒険・文化・物語の量の三つが、いちばん無理なくそろう。** 霧が晴れて地図に島が描かれる発見が毎回起き（冒険）、それを起こす道具が寄木の羅盤・高札・一里塚・呼び太鼓（文化）で、地図が埋まること自体が物語になる（物語はサブのまま）。
2. **文化が「旅の道具」として入るので、授業にならない。** 遊ぶ人は「針を刺す箱」「決まりの札」「休む塚」として使い、何なのかは任意の道中帳でだけ知る。第2回の「中くらい」より厚いが、遊びの邪魔をしない。
3. **仕組みとの一致がいちばん強い。** W/A/S/D＝東西南北の針で、ブロックが世界の向きで動く今の仕様とずれない。高札は「島の決まり」で、禁止が罰にならない。
4. **いちばん安く、今のモデルがそのまま使える。** フードの旅人に笠、チェックポイントは一里塚と提灯、街灯は提灯、柵は四つ目垣。新しく要るのは針・札・道標・標石・地図台・茅葺の家など、単純な形が多い。
5. **宗教の物に近づかずに済む。** 街道の道具と建物だけで世界ができる。

次点: **案C「かぜまち船」**。船のハブがいちばん「冒険らしい」ので、制作費を払ってでも乗り物の旅にしたいならこちら。PR #57 の燕尾の旗（吹き流し）・ランタン（常夜灯）・羽根（追い風）・鐘（船鐘）がいちばん自然に合う。
組み合わせ: A を選んでも、C の**凧**（ハブのおもちゃ）と B の**提灯が増えるハブ**は借りられる（A の文化の内訳にすでに入れた）。
