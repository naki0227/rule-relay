### 引き続き守ること（第1〜3回から）

## 0. 4案の一覧と、「ファンシーでも安っぽくしない」ための約束

| 案 | 仮題 | 冒険の形 | 文化 → ファンタジーの芯 | 画面の素材 |
|---|---|---|---|---|
| A | **うきにわ** | 雲の鯉に乗って、空に浮かぶ盆栽の庭を渡る | 盆栽・苔玉・関守石・錦鯉・金継ぎ・藤棚 | 釉薬の磁器・苔・光る種・金継ぎの金 |
| B | **ほしわたり** | 宵の空の島々を、星の川をたどって渡り、星の橋を架ける | 七夕・天の川・蛍籠・吹き流し・折り鶴・螺鈿 | 月光の乳白ガラス・星の粒・薄い光の帯 |
| C | **ゆめまつり** | 四季の夢の祭りの島をめぐり、島ごとの大花火を上げる | 花火・提灯・風車・団扇・雪あかり・藤 | 色ガラスの提灯・紙風船の光・花火の粒 |
| D | **からくり星函** | 大きな魔法の宝石箱の中の段と引き出しを旅する | からくり人形・ぜんまい・七宝・螺鈿・組子・和時計・手まり | 螺鈿の虹色・七宝の色・金の金具・ベルベット |

ファンシーでも安っぽくしない約束（4案共通。AI の判断）:

1. **色の段を決める**。地（明るく淡い）→ 地形（中くらいの彩度）→ 差し色（澄んだ宝石の色、面積は1割以下）→ 状態の色（UI だけ）。蛍光色・原色のベタ塗りは使わない。真っ白と真っ黒も使わない（文字は濃い藍・すもも色など）。
2. **光は「縁」と「小さな点」だけ**。画面全体を光らせない。発光は能力・器・ゴール・生き物の目印に限り、粒子は1画面に数十個まで。
3. **線と角丸をそろえる**（今の UI の約束を引き継ぐ）。線は 2px（選択中 3px）、角丸はパネル 22〜28・枠 14・チップは全丸。飾りの模様は**角と区切りの1か所だけ**に置く。
4. **書体は2つまで**（見出し1つ・本文1つ）。手書き風の書体は見出しか生き物の一言だけに使い、数字と操作の案内には使わない。
5. **形で役割を示す**（色だけに頼らない）。選択＝縁が太く浮く、有効＝右上の点、貸出中＝下の帯と外向きの矢印、禁止＝赤い輪と斜線。これは4案とも同じ形で、素材だけ変える。

Godot 4.6 で作れる範囲（4案共通。重い機能は使わない）:

- 地形と部品: `StandardMaterial3D` の **縁の光**（`rim_enabled`・`rim_tint`）と、**トゥーンの陰**（`diffuse_mode = DIFFUSE_TOON`、`specular_mode = SPECULAR_TOON`）。または、2〜3段の明るさの帯を作る短い自作シェーダー（30行ほど）。
- 光るもの: `emission` と `WorldEnvironment` の **glow**（HDR のしきい値を高めにして、光る物だけにかかるようにする）。
- 空: 自作の **sky シェーダー**（`shader_type sky;` で上下のグラデーション＋雲や星の点をノイズで描く）か `ProceduralSkyMaterial`。遠景の島や雲は、カメラを向く板（ビルボード）の絵。
- 霧: 距離の霧（`fog_enabled`、空の色に合わせる）。**体積の霧（volumetric fog）は使わない**（審査機の GPU と lavapipe での確認のため）。
- きらきら: `GPUParticles3D`（少数）。審査機で重いときは `CPUParticles3D` に替えられるよう、数を設定にまとめる。
- UI: `StyleBoxFlat`（角丸・線・影）と、飾りの部分だけ `NinePatchRect`（角の金具・帯の模様・縁のグラデーション）。グラデーションの縁は `StyleBoxFlat` では描けないので9分割の画像にする。

## 案A　うきにわ —「ひとりじゃ、花はひらかない。」

- **仮題**: 『うきにわ』／英 *Ukiniwa: The Floating Gardens*（別案: 『こいぐもの浮庭』）
- **一言**: 空に浮かぶ盆栽の庭の島々を、雲でできた鯉の背に乗って渡り、光る種を貸し借りして庭を育て、全員で島のてっぺんの大きなつぼみをひらかせる。

### A-1. 冒険

- 淡い空に、鉢ごと浮かぶ大小の庭がいくつも漂っている。大きな庭は丘や崖や小さな森を持つ「島」で、そのあいだを**雲の鯉**（くもごい）がゆっくり泳いでいる。
- 探検隊は鯉の背に乗って次の庭へ渡り、苔の斜面・藤の棚・割れた古い鉢の崖を歩いて登る。島ごとに、てっぺんに**閉じたつぼみ**がある。
- 発見: 庭の裏側に隠れた小さな鉢（秘密の苔玉）、金継ぎで直せる割れた鉢、遠くの庭へ泳いでいく鯉の群れ。島は鯉の通り道と、つたの橋で**ひとつながり**（ロード画面で区切らない見せ方ができる）。

### A-2. 舞台

- 空の上の「庭の群れ」。地面はない。下には雲の海がひろがり、昼は淡い空色から桃色へのグラデーション。
- 庭は**磁器の鉢**に植わっている。島の崖の下のほうは鉢の釉薬（藤色・青磁・乳白）で、上へ行くほど土と苔になる。崖が「鉢の縁」になっているので、ブロックの段がそのまま「鉢の段」に見える。
- 住人は、頭に芽のある卵形の**芽ぐみ**（めぐみ。今の生き物）。庭を育てるのが好きで、高い所の日だまりに行きたがる。

### A-3. 仕組みの言い方

| 仕組み | 世界での言い方 |
|---|---|
| 器と能力トークン | 動きは**ひかり種**（ひかりだね）という光る種に宿っている。種は**苔玉鉢**（こけだまばち。手のひらにのる釉薬の小鉢に苔玉）に眠っていて、物に植えると、その物は種の育つ向きへ動く。鉢は手もとに残り、種だけが行き来する（ADR 0005 と同じ）。 |
| それぞれの能力 | W/A/S/D＝**根の種**（根が伸びる向きへ押す）／ジャンプ＝**竹の種**（竹がぐんと伸びて跳ね上げる）／投げる＝**ほうせんかの種**（実がはじけて遠くへ飛ばす）／登る＝**つたの種**（つたが崖をつかむ）／ダッシュ＝**綿毛の種**（綿毛が風に乗る） |
| 禁止の札 | **とめ石**（関守石を元にした）。縄を十字にかけた丸い石で、置かれた物には、どの種も根を下ろさない。「この先へは入らないで」という庭の決まりで、誰かの罰ではない。持ち歩く袋（かばん）の中でも効く（「庭の決まりは、袋の中でも守られる」）。縄は禁止の赤。 |
| 単発・繰り返し・信号 | **ひと咲き**（一度咲いたら種が戻る）／**根づき**（抜くまで植わったまま）／**鯉うた待ち**（庭鐘を鳴らすと雲の鯉が低い声で歌い、歌が聞こえている間だけ動く） |
| 鐘（音源） | **庭鐘**（にわがね）。釉薬をかけた陶の鐘を引き綱で鳴らす。鯉が応えて歌う（鯉の歌が届く範囲＝信号の届く範囲） |
| 願いを持つ生き物 | **芽ぐみ**。命令は聞かないが、種をもらうと自分の行きたい方へ使う。頭の芽が細長い葉を一枚立て、そこに願いの絵（↑ 高い所へ／巣へ帰りたい／…）が光る。字は書かない |
| 1〜4人がゴールに集まる | 島のてっぺんの**大つぼみ**は、花びらの上に全員が立ったときだけ、重さと温かさでひらく。「ひとりじゃ、花はひらかない」。ひらいた花から光の花粉が舞い、次の庭への鯉の道が見える |
| ハブと成長 | **はじまりの鉢庭**。大きな一本の盆栽と、割れた大鉢のまわりの小さな庭。島のつぼみをひらくたびに、盆栽に枝が一本伸び、割れ目が一本**金継ぎ**でつながり、鯉が一匹増え、藤棚・東屋・飛び石が足される |
| ひとつながりの島 | 庭と庭は**つたの橋**と**鯉の通り道**でつながる。ハブの盆栽の枝の先が、それぞれの島への入口 |

標語の言い換え: **「庭の決まりは厳格に。育て方は自由に。」**

### A-5. 物語（前置き5行まで）

1. 空の庭は、昔は一つの大きな庭だった。
2. 大鉢が割れて、庭はばらばらに空へ散った。誰のせいでもない。
3. 散った庭のてっぺんでは、つぼみが閉じたまま眠っている。
4. 庭師見習いの探検隊が、雲の鯉に乗って最初の庭へ渡る。
5. 雲のいちばん上に、すべての種が生まれた「はじめの盆栽」があるという。

最後の一場面: はじめの盆栽で全員が大つぼみをひらくと、ハブの大鉢の最後の割れ目が金でつながり、散っていた庭が鯉に引かれてゆっくり寄ってくる。

### A-7. 音楽

- 低いマリンバ・木の打楽器・アコースティックギター・ウッドベースに、**十七絃箏**（低い箏）の撥弦と、柔らかいシンセのパッド。
- 雲の鯉の歌は、低いチェロのハーモニクスと人の声の「ハミング」（低め・言葉なし）。信号の音もこれにそろえる。
- つぼみがひらく瞬間は、ハープ（低い音域）のアルペジオと弦の和音。
- 使わない: チェレスタ・グロッケン・風鈴・鈴（高い）、鹿威しの「カコーン」（決まり文句）。

### A-8. 危険と制作費

- **制作費: 中**。新規は苔玉鉢・とめ石・庭鐘（今の鐘の作り直し）・雲の鯉（半透明の泳ぐ板か、低ポリの体に縁の光）・大つぼみ・金継ぎの線（光る線のメッシュ）・鉢の縁の地形の塗り分け。木・鉢植え・ベンチ・柵は今のモデルの塗り替えで済む。
- **危険**:
  - 庭は「止まった景色」になりやすく、冒険の感じが薄れる → 鯉に乗って渡る・割れた鉢の崖を登る・裏側の秘密の鉢、で「渡る・登る・見つける」を毎島入れる。
  - 錦鯉は紅白の印象が強く、赤を使えない → 桃・金・白金・藤の鯉にする（「黄金」「プラチナ」のような実在の色柄もある）。
  - 庭は寺の庭と結びつきやすい → 枯山水・灯籠・蓮・蹲踞は出さない。石は関守石と飛び石、灯りは行灯。
  - 「空に浮かぶ島」は広く使われる題材 → 「鉢ごと浮かぶ盆栽」「雲の鯉」「金継ぎで直る」で独自性を出す。

## 案B　ほしわたり —「星の橋は、みんなで架ける。」

- **仮題**: 『ほしわたり』／英 *Starferry Isles*（別案: 『ほしわたりの島』）
- **一言**: 宵の空に浮かぶ島々を、地上を流れる星の川をたどって渡り、蛍籠に入れた星を貸し借りして、全員で星の橋を架けていく。

### B-1. 冒険

- いつも「宵」（日が沈んだすぐ後の、桃色と藤色の空）の世界。島と島のあいだを、浅く光る**星の川**が流れていて、膝までの浅瀬は歩いて渡れる。

### B-7. 音楽

- 低いハープ・柔らかいマレットのヴィブラフォン・ウッドベース・弦のパッドに、**十七絃箏**の和音。
- 星鐘は低い青銅とガラスの中間の音（余韻長め、高い倍音を削る）。
- 橋が架かる瞬間は、低い弦の上昇と合唱の「アー」（低め）。
- 使わない: チェレスタ・オルゴール・風鈴・ウィンドチャイム（星の題材で使いがちだが甲高い）。

  - 光る物が増えると審査機で重い → 粒子の数を設定で絞れるようにする。

## 案C　ゆめまつり —「大花火は、みんながそろってから。」

- **一言**: 季節ごとの夢の祭りが浮かぶ島々をめぐり、花火玉に詰めた火花を貸し借りして、島ごとの大花火を全員で打ち上げる。

### C-1. 冒険

## 案D　からくり星函 —「歯止めは厳格に。からくりは自由に。」

- **仮題**: 『からくり星函』（からくりほしばこ）／英 *The Karakuri Starbox*（別案: 『ねじまき星函』）

### D-1. 冒険

- 旅の一行は、昔の職人が作った巨大な宝石箱の中にいる。箱の中には段・引き出し・小部屋がいくつもあり、それぞれに草や木の生えた小さな世界（島）がある。

- 発見: 引き出しの奥の小さな隠し函、蓋の裏に描かれた空、歯車の隙間から見える別の島。

### D-2. 舞台

- 空は**蓋の裏の絵**。淡い水色から杏色へのグラデーションに、金の蒔絵の雲と星が描いてあって、ゆっくり回っている（昼のように明るい）。
- 地面はベルベットのような草、崖は黄楊と寄木の木肌、ところどころに七宝（金属に色ガラスを焼き付けた）の青緑と桃色のタイル。金の金具と螺鈿が光を返す。
- 住人は**ねじめ**（今の卵形の生き物の、ぜんまい仕掛けの版）。頭の芽は、ぜんまい（植物の渦巻いた芽と、巻きばねが同じ名前）の形をしている。

### D-5. 物語（前置き5行まで）

1. 昔の職人が、世界を一つの箱にしまった。
2. 箱の曲が止まり、引き出しは閉じたまま。
3. 箱のいちばん手前で、小さな一行がぜんまいを見つけた。
4. 一節ずつ曲を進めれば、次の引き出しが開く。
5. 箱のいちばん奥には、まだ誰も聞いたことのない最後の一節がある。

最後の一場面: いちばん奥で全員が回り舞台に乗ると、曲が最後まで流れ、蓋が大きく開いて、箱の外の本物の空が見える。

### D-7. 音楽

- クラリネット・バスクラリネット・ファゴット・ウッドベース・低いカリンバ・木琴に、**十七絃箏**。ハブの曲は島ごとに楽器が一つ増える。
- オルゴールの音は**低い櫛歯**（1〜2オクターブ下げた音域）だけを使い、節鐘の合図にだけ鳴らす。
- 使わない: 普通の音域のオルゴール・チェンバロ（高く硬い）・時計のカチカチの連続（似すぎ・リアル）。

### D-8. 危険と制作費

- **制作費: 中〜大**。回り舞台（回る床）・歯車の飾り・引き出しの開く演出・組子の橋・蓋の裏の空・人形の段階。七宝・螺鈿の質感は手続きテクスチャで作れるが、試しが要る。
- **危険**:
  - **オルゴールは甲高い**（本人が嫌う音） → 低い櫛歯と管楽器を主にする。それでも題材そのものが「高い音」を連想させる。
  - 箱の中は**屋外の冒険の感じが薄い**（「ひとつながりの島」「オープン」と少しずれる） → 引き出しの中に空と草原がある、と見せる。
  - 歯車と真鍮は、既存の「スチームパンク」の見た目に寄りやすい → 歯車は見せすぎず、木・七宝・組子・螺鈿を主にする。
  - 機械は冷たく見えやすい → 木と布と光で温かくする。

## 3. 推奨: 案A「うきにわ」

1. **ファンシーなのに落ち着いて見える。** 乳白の磁器・藤の釉・苔・金継ぎの金、と素材の数が少なく、パステルでも安っぽくなりにくい。PC の製品版の統一感を保ちやすい。
2. **仕組みの言い方がいちばん「当然」に見える。** 竹がぐんと伸びる＝跳ぶ、つたが崖をつかむ＝登る、ほうせんかがはじける＝投げる、綿毛が風に乗る＝ダッシュ。能力ごとに形がまったく違うので、アイコンも見分けやすい。禁止の**関守石**は「この先へ入らないで」を示す実在の庭の石で、宗教の物ではなく、そのまま禁止の意味を持つ。
3. **文化の入れ方が「魔法に変えた日本」になる。** 盆栽が空に浮かび、錦鯉が雲になり、割れた鉢が金継ぎで光ってふさがる。元の形はわかるが、歴史の再現ではない。
4. **今のモデルがいちばん生きる。** 頭に芽のある卵形の生き物は「芽ぐみ」そのもので、木・鉢植え・柵・ベンチは塗り替えで済む。制作費は4案でいちばん安い。
5. **音の好みに合わせやすい。** 低い木の打楽器・箏・人の声のハミング（鯉の歌）で、甲高い音を使わずに不思議さを出せる。

次点: **案B「ほしわたり」**。いちばん魔法らしく、七夕の短冊と「願いを持つ生き物」がきれいに合い、今の燕尾の旗が吹き流しにそのまま使える。宵の空を明るく保つ工夫と、光の調整の手間を払えるならこちら。
組み合わせ: A を選んでも、B の**星の川**をハブの夜の景色（任意）に、D の**ハブの曲が育つ**をハブの成長に借りられる。

## 5. 未確認のこと

- タイトル案（うきにわ・ほしわたり・ゆめまつり・からくり星函・Ukiniwa・Starferry Isles・Dreamfair Isles・The Karakuri Starbox ほか別案）の同名作・商標は**調べていない**。決める前に調べる。

- 書体の見え方を Godot の中で確かめていない（字の幅・行の高さ・小さい字の読みやすさ）。特に Yusei Magic・Kaisei 系は小さい字に向かないので、見出しだけに使う前提。
- 縁の光・トゥーンの陰・glow・sky シェーダーが Windows の審査機と lavapipe で重くないかは試していない。
- 低い櫛歯のオルゴール（D）、雲の鯉の低いハミング（A）、星鐘（B）を Stable Audio などで作れるか、甲高くならないかは試していない。
- 文化の説明（関守石・段返り人形・ぜんまいの名前の由来・七宝・螺鈿など）は AI の知識で書いた（Web では確かめていない）。画面や帳面に載せるときは公的な資料で確かめ直す。
