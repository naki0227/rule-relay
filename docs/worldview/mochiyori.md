## 1. 設定資料（ロアバイブル）

### 島々

海の上に、小さな島がいくつも浮かんでいる。島は秋になると風にほどけて散り、春になると寄ってくる。島の者たちはそれを「島の渡り」と呼び、悲しいことだとは思っていない。散った島を迎えにいくのは、毎年の楽しみのひとつだから。

春のはじめ、どの島からもいちばん遠くに見える浜で、**大もちより**が開かれる。島じゅうの者が食べ物と「できること」を持ち寄って、一本の長い卓に並んで食べる。いちばん大事な決まりはひとつだけ。

> いただきますは、そろってから。

### 「できる」と器

この島々では、跳べること・進めること・投げられることは、体に付いたものではなく、**卓に出すもの**だと考えられている。子どもは小さいころから、自分の「できる」を器（うつわ）に盛って、ほかの者に取り分けるように教わる。

器は動かない。棚に置いたまま、中身だけを取り分ける。だから誰かに盛った「はねる」は、どこへ行っても、もとの器を覚えている。ひとくち分なら、使い終わると、盛ってくれた者の手もとへひとりでに戻ってくる。盛ってくれた者が卓を離れていたら、その場に置かれて誰かが拾うのを待つ。

同じ「できる」を何人分も重ねると**大盛り**になる。はねるが大盛りなら高く、まえへが大盛りなら速く、とどけるが大盛りなら遠くまで。大盛りに上限はない。けれど、全員がそろわなければいただきますにならないから、ひとりが全部をかかえこんでも島は応えない。

### 作法

食卓には作法がある。作法は「できる」より強い。

いちばんよく見る作法は**おあずけ札**だ。札が付いた物は、その「できる」を持っていても使わない。札を手もとに持てば、自分もおあずけになる。風呂敷の奥にしまっても、言いつけは忘れない。札は捨てられないが、別の物に付けかえることはできる。どこに付けかえるかは自由だ。

作法は厳しいが、何を持ち寄るか、どう取り分けるかは誰にも決められていない。
**作法は厳格に。持ち寄りは自由に。**（＝ルールは厳格に。解法は自由に。）

### 渡し手

散った島を訪ね、島の食卓に皆で着いて、その島を大もちよりへ招いてくる役目を**渡し手**（わたして）という。長い腕で器を手渡しするのが得意な、島の若い世話役たち。ひとりで行くこともあれば、四人で行くこともある。人数に合わせて、島はいつも少しだけ器を余分に用意してくれている（人数別補助）。

渡し手が島から落ちても、けがはしない。ふわりと**湯気**になって、仲間を上から見守る。誰かがひと休みのござに着けば、みんな起き上がれる。どうしてもうまくいかないときは、みんなで手を挙げて**仕切り直し**（全員リセット）をする。

あとから来た渡し手は、すぐには卓に着けない。次の仕切り直しのときに、席がひとつ用意される。島の者は言う。「**席は、いつもひとつ空けておくもの**」。

### おきゃくさん

島には、島ごとの**おきゃくさん**が住んでいる。おきゃくさんは頼みを聞かない。出されたものを、自分の好きなように使う。見晴らしのいい席に座りたいミハラシは、「よじる」をもらえば崖を登り、「はねる」をもらえば石を跳んで上へ行く。木の実を抱えたミハラシは、「とどける」を受け取ると、向いている方へお返しの木の実を投げる。けれど、おあずけ札が付いていれば、どんなに行きたくても待つ。

### 呼び鐘

どの島にも、ごはんの合図の**呼び鐘**がある。鐘が鳴っている間だけ動く「合図盛り」の物は、音が届かなくなると手を止め、また鳴れば動き出す。

### 島の食卓

島のいちばん奥には、少しくぼんだところに、その島の**食卓**（掘りごたつのような、縁より1段低い卓）がある。座布団は来た渡し手の数だけ。全員が座ると座布団が灯り、手を合わせて「いただきます」。島はそのお礼に、おきゃくさんを一人、浜の寄り合いへ送ってくれる。

### いちばん古い卓

浜の年寄りは、いちばん遠くの峰に、島が散るよりずっと前の、いちばん古い卓があったという。その卓の座布団は、数えきれないほどあったらしい。

## 4. エンディング案

1. 「大鍋峰への遠出」の峰の奥に、いちばん古い卓がある。座布団は苔むしていて、数えきれないほど並んでいる。渡し手が全員座ると、苔の下の座布団が一つずつ灯っていく（これまでの島の数だけ）。
2. 「いただきます」。画面が浜へ戻ると、渡し板の向こうから全部の島が寄ってきて、浜につながる。
3. 大もちより。長卓に全部のおきゃくさんが並び、渡し手の席は人数分。全員で「いただきます」（ここだけ、クリアと同じ合図を全員が押す）。料理を食べる様子の固定カメラの数枚の上で、スタッフの名前が流れる（動きの少ない絵で安く作れる）。
4. 最後の一枚: 長卓の端に、**誰も座っていない席が一つ**。新しい器と、湯気の立つ椀。字幕は一行だけ。

   > 席は、いつもひとつ空けておく。

5. タイトルへ戻ると季節が秋になっていて、島は少しずつほどけていく（周回の動機。初回の報酬は二度と出ないが、記録と箸置きを集めに行ける）。

ねらい: 戦いも勝利もなく、「みんなそろった」で終わる。空いた席は、次に一緒に遊ぶ誰か（オンライン協力に誘う動機）を指す。

## 7. 音楽と効果音の方向（この案のとき）

- ハブ: アコースティックのフォーク（いまの B1/B2 の方向）。島を一つクリアするごとに、浜の呼び鐘が鳴らせる音が増える程度の小さな変化にとどめる（案B のように曲そのものを層で作り込むのは費用が大きい）。
- 考える場面: フェルトピアノとチェロ（B3/B4 の方向）。
- タイトル: 軽い室内楽（B5/B6）でも合うが、ギターとマリンバの短い前奏にすると浜の曲と一続きに聞こえる。
- 呼び鐘: 低い青銅の鐘か、木の板の「ゴーン」。主な音程は 1100Hz 未満（`tools/sfx/test_sfx.py` の基準）。
- いただきます: 全員の手を合わせる「パン」（人数分を少しずらして重ねる）＋短い和音。高い鈴は使わない。
- 下げる（F）: 焼き物の器を重ねる「コトッ」。おすそわけ（付与）: 木の器を卓に置く音。今の「島の物そのものが楽器」の方針（`docs/sound-design.md`）とそろう。

## 8. 危険と手当て

| 危険 | 手当て |
|---|---|
| 料理を作る遊びを期待される | 料理は報酬と飾りだけ。島では作らない。紹介文で「持ち寄りの寄り合い」と言い、料理ゲームと名乗らない |
| 食べ物の協力ゲームと比べられる | 時間制限・注文・調理をしない。核は「器」と「作法」で、遊びは箱庭パズル |
| 能力を「食べる」と誤解される | 食べない。器は持つ・盛る・下げるだけ。「いただきます」は島の食卓に着いたときの合図だけ |
| 日本の言葉が海外で伝わらない | 英語版は *Potluck Isles* とし、用語は意味で訳す（ひとくち→One Bite、おかわり→Seconds、おあずけ→Not Yet）。提出版は日本語が先 |
| 子ども向けに寄る | 食卓の作法・季節のめぐりは大人の生活の言葉。色は彩度中くらい、画面は落ち着いた昼下がりの光 |
| タイトルの同名作・商標 | 決める前に調べ直す（2026-11-20 は簡単な検索だけ） |
