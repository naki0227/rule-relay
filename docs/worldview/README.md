## 0. どの案にも共通する条件

世界観は、次の仕組みが**物語の中で当然に見える**ように作る。説明の文章で補わない。

| 仕組み | 世界観が答えること |
|---|---|
| 能力（W/A/S/D・ジャンプ・投げる・登る・ダッシュ）は「器」に入ったトークンで、ブロック・地形・生き物・仲間に貸せる | なぜ「できること」が物で、手渡せるのか。なぜ器は動かず中身だけが動くのか |
| 禁止の札は能力より強い | 札は世界の中で何なのか。なぜ「持っていても使えない」のか |
| 発動方式: 単発・繰り返し・信号（鐘の音） | 3つの方式が、世界の習慣としてどう呼ばれるか |
| 1〜4人で能力を回し、全員がゴールに集まってクリア | なぜ「全員」なのか（1人が着くだけではだめな理由） |
| 生き物は命令を聞かず、願いで動く | 生き物は何者で、何を願うのか |
| ハブから入口を選んで島へ行き、初回クリアでハブが育つ（ADR 0008） | ハブは何で、何が育つのか |
| 標語「ルールは厳格に。解法は自由に。」 | 世界のどこが「厳格」で、どこが「自由」か |

守ること:

- **完全に独自**。既存の作品・キャラクター・設定・名前をまねない。AI の生成でも、特定の作品や作家の画風を指す指示（「○○風」）を書かない（コンテストの AI 利用ガイドライン）。
- **戦闘・敵・ボスを主軸にしない**（本人の方針）。にぎやかで笑える協力にする。
- **ゆるふわで温かい3Dブロックの箱庭**。子ども向けに寄りすぎず、PC の製品版の仕上げ。暗い重厚な画面・量産的なインディの見た目は避ける。
- **少人数で作れる**。島はブロックの地形のまま、足すのは小物と生き物と少数の目印。
- 音は低く温かく、こもらず、似すぎず、リアルすぎない（`docs/sound-design.md`）。
- 色は UI のトークン（`src/ui/ui_theme.gd`。生成り `#fff8ec`・こげ茶 `#4d3a2c`・夕日 `#f09a45`・若葉 `#76a85f`・はちみつ `#e2a72e`・禁止 `#e0644f`）と地形の色（草 `#84bd5f`・土 `#b88a5c`・石 `#b3a48e`・砂岩 `#e6c995`）を土台にし、案ごとに差し色を足す。**禁止の赤は禁止にだけ使う**（どの案でも、ほかの物に赤を使わない）。

いまのステージ（目安時間の短い順。`StageCatalog.all_stages()`）:
跳ぶ力を貸す 3分／鐘の谷 4分／みんなで回す 5分／丘の上の旗 8分／けものの巣 10分／採石場 12分／風の尾根 15分／札の庭 18分／三つの鐘の島 20分／砦跡 25分／浮島めぐり 30分／遠征 40分。

## 案A　もちより島 — 「いただきますは、そろってから。」（推奨）

- **仮題**: 『もちより島』／英 *Potluck Isles*（別案: 『おすそわけ諸島』、副題「いただきますは、そろってから。」）
- **一行**: 「できる」を器に盛って分け合う島々で、渡し手たちが島ごとの食卓に全員そろって「いただきます」を言いにいく、協力の箱庭パズル。

**舞台と島がある理由**
島々は秋に散り、春に寄る。年に一度の「大もちより」（島じゅうの者が食べ物と“できること”を持ち寄る寄り合い）の前に、ばらばらに漂う島をひとつずつ訪ね、島の食卓に皆で着いて、その島を寄り合いへ招く。島が散るのは災いではなく季節のめぐりで、悪者はいない。

**ハブ**: 「寄り合いの浜」。短い長卓がひとつと、西から東へ並ぶ渡し板（桟橋）。桟橋の先の幟（のぼり）が島の入口。のれんのようにくぐると島へ渡る（部屋も扉もない）。

**能力が貸せる理由／禁止の札**
この島々では、「できる」は人の持ち物ではなく、**食卓の物**だと考えられている。だから、器（うつわ）に盛って取り分け、配り、下げる。器は棚に残り、中身だけが行き来する（ADR 0005 の「器は動かない、トークンだけが動く」と同じ）。
禁止の札は「**おあずけ札**」。食卓の決まりは食欲より強い。ジャンプを大盛りで持っていても、おあずけと言われたら跳ばない。札は風呂敷（かばん）の中でも効く（「言いつけは忘れない」）。

**プレイヤー・生き物・鐘**
- プレイヤーは**渡し手**（わたして）。長い腕で器を手渡しする島の若い世話役（主人公の長い腕の案と合う。主人公のデザインは未決のまま）。
- 生き物は**島のおきゃくさん**。命令は聞かない。出されたものを好きなように使う（「おきゃくは好きに食べる」）。願いは「見晴らしのいい席に座りたい」「子どもを晩ごはんまでに巣へ帰したい」など。木の実を持つおきゃくは、「とどける」を受け取るとお返しに木の実を投げる。
- 鐘は**呼び鐘**（ごはんの合図）。鳴っている間だけ動く「合図」の盛り方がある。

**全員がゴールに集まる理由**: 「いただきますは、全員そろってから」。ゴールは島の食卓。縁より1段低い窪み（ADR 0011 決定 10）は、そのまま**掘りごたつの食卓**になる。座布団が人数分あり、座った人の分だけ灯る。全員座ったら「いただきます」でクリア。

**トーン・色・素材**: 昼下がりの野外の食卓。白木・焼き物・麻の布・紙の幟・行灯の灯り。
`#fff8ec` 生成り／`#ecd3a8` 白木／`#b9825a` 焼き物の土／`#8cbf6a` 若菜／`#e2a72e` はちみつ（貸出中）／`#f6c98a` 行灯の灯り／`#d7e9ee` 湯気の空／`#e0644f` おあずけ札（禁止にだけ）

**音楽**: アコースティックのフォーク。ナイロン弦ギター・木のマリンバ・手で鳴らす打楽器・ウッドベース（いま生成済みの B1/B2 の方向そのまま）。考える場面はフェルトピアノとチェロ。呼び鐘は低い青銅の鐘か木の板の「ゴーン」で、甲高い鈴は使わない。クリアの「いただきます」は全員の手を合わせる音＋短い和音。

**物語の伝え方**: ハブの長卓の**空いた席**が「まだ来ていない島」を示す。島に着くと、食卓が半分だけ整っている（器が足りない、座布団が濡れている）。看板は1行（「ここから先、はねるのは おあずけ」）。生き物の頭の上の記号（↑？…）はそのまま。

**進行とメタ**: 初回クリアごとに、その島のおきゃくさんがハブへ来て、長卓が1区画伸び、料理が1皿並ぶ。屋台・提灯・新しい浜が増える。**長卓の長さがそのまま進み具合**になる。収集品は「箸置き」（島ごとの小さな記念品）、衣装は手ぬぐい・前掛け。

**強み**: ゲームの言葉が日本語の食卓の言葉にそのまま重なる（器・おあずけ・おかわり・ひとくち・取り分け・下げる・大皿・大盛り・いただきます）。全員ゴールの理由が誰にでも分かる。禁止が「罰」でなく「作法」になり、本人の「妨害しない」方針と合う。
**弱み・危険**: 料理を作る遊びを期待される（作らない。料理は報酬と飾りだけ）。食べ物の協力ゲームと比べられる。英語ではしゃれが伝わりにくい。
**制作費**: 小〜中。新規の必須モデルは食卓セット・器・札・ござ・幟・長卓の区画など、ほとんどが単純な木と布の形。

**島の名前（案）**

| 今の名前 | 案 | ひとこと |
|---|---|---|
| 跳ぶ力を貸す | ひとくちの岩棚 | 初めての「ひとくち」（単発） |
| 鐘の谷 | 呼び鐘の谷 | 谷の向こうの呼び鐘を、おすそわけ筒で鳴らす |
| みんなで回す | まわし椀の段 | ひとつの椀を回して全員上がる |
| 丘の上の旗 | 見晴らし丘のおぜん | 丘の上の食卓 |
| けものの巣 | ミハラシの巣 | 子どもを晩ごはんまでに巣へ |
| 採石場 | 塩の石切り場 | 塩の石を押して段にする |
| 風の尾根 | 干し場の尾根 | 干し棚と風鳴りの板 |

| 三つの鐘の島 | 三つの呼び鐘 | 三つの合図で島じゅうを呼ぶ |
| 砦跡 | 重石の古蔵 | 要石＝漬物蔵の重石を戻す |

## 案B　ひびきの島 — 「ひとりじゃ、和音にならない。」

- **仮題**: 『ひびき渡し』／英 *Chime Relay*（別案: 『こだま諸島』）
- **一行**: できることがすべて「節（ふし）」として響いている島々で、歌い手たちが節を貸し借りし、島の歌を全員でそろえて鳴らす。

**舞台と島がある理由**: 島々は、昔ひとつの大きな鐘楼のまわりで歌い合っていた。鐘が一つずつ外れ、島は自分の節だけを口ずさむようになり、離れていった。

**ハブ**: 空っぽの「鐘楼の村」。吊り台だけが並び、鐘は一つも吊られていない。入口は島ごとの小さな鐘の台。

**能力が貸せる理由／禁止の札**: 「跳ぶ」「進む」は、物に教えられる短い節。節は**巻き貝の器**に入っていて、吹いて渡すと相手がその節を覚える。器は手元に残る（節を教えても、貝は渡さない）。禁止は「**しずか札**」。その節を消音にする布の札で、どれだけ節を持っていても鳴らない。

**プレイヤー・生き物・鐘**: プレイヤーは**歌い手**（遠くへ声を届ける、長い腕の住人）。生き物は自分の好きな歌を探す者で、気に入った節だけを使う。鐘は島の「合図」そのもので、信号の方式は「鐘が鳴っている間だけ歌う」。単発＝**一節**、繰り返し＝**輪唱**、合図＝**鐘待ち**。

**全員がゴールに集まる理由**: ゴールは**歌い台**。島の歌は全員の声がそろったときだけ和音になり、島の大鐘が戻ってくる。

**トーン・色・素材**: 夕方の高原。真鍮・杉・苔・霞。
`#f7efe0` 象牙／`#c9a35c` 真鍮（くすみ）／`#7a5a43` 杉／`#8fae6b` 苔／`#f2b27a` 夕焼け／`#d9e8ef` 霞の空／`#e0644f` しずか札（禁止にだけ）

**音楽**: 適応型。島を一つクリアするたびに、ハブの曲に楽器が一つ足される（低い鐘・チェロ・木管・手拍子…）。素材は Stable Audio の長い曲を楽器の層ごとに作る。鐘は**低い青銅と木の板**に限り、甲高い鈴やチャイムは避ける。

**物語の伝え方**: 島の歌の一部が、地形の形（音の波の形の岩、こだまの洞）に描かれている。言葉はほぼ無し。

**進行とメタ**: 島をクリアすると、その島の鐘がハブの鐘楼に吊られ、ハブの曲が一層豊かになる。全部そろうと、鐘楼で全員で鳴らす大合奏。

**強み**: 信号（鐘）の仕組みが世界の中心になり、協力＝合奏という分かりやすさ。音で進み具合が分かる体験は記憶に残る。
**弱み・危険**: 音が本人の一番の苦手（高い・こもる・似る）で、その音に世界観を預けることになる。音を切って遊ぶ審査員には伝わりにくい。「歌で世界を戻す」は物語として既視感が出やすい。
**制作費**: 中。モデルは少ないが、層ごとの曲・島ごとの節の音・鐘の音色の作り込みが重い。

**島の名前（案）**: はじめの一節／鳴らずの谷／輪唱の段／こだまの丘／子守唄の巣／石琴の石切り場（低い石の木琴）／風鳴りの尾根／しずか札の庭／三和音の島／鐘楼跡／遠音の浮島／大合奏への旅

## 案C　ためしびと — 「ちゃんと遊べるか、確かめてきて。」

- **仮題**: 『ためしびと』／英 *Tryfolk*
- **一行**: 留守にしている模型師の作業場で、木彫りの小さな試し人形たちが、作りかけの箱庭が本当に遊べるかを確かめる。

**舞台と島がある理由**: 島は、模型師が作っている**ジオラマ**。どれも「仕様」（できること・してはいけないこと）が付箋で決められている。模型師は人に見せる前に、試し人形に通し遊びをさせる。ブロックの見た目は、そのまま「木の部品でできた模型」だから。

**ハブ**: 作業台の上。道具・方眼紙・糸巻きが巨大な地形になる。棚にジオラマが並び、それぞれの前の小さな台に乗ると、その中へ入る（中では空も遠景もある普通の島）。

**能力が貸せる理由／禁止の札**: 能力は模型師が彫った**部品の駒**。差し込むとその物がその動きをする（いまの能力ブロックの木の栓と合う）。駒の台座（器）は棚に残る。禁止は**付箋**（「ここ ジャンプなし」）。模型師の書き込みは駒より強い。

**プレイヤー・生き物・鐘**: プレイヤーは試し人形。生き物は模型師が作った「住人」の人形で、模型師が書いた願いの札に従って動く。鐘は作業台の**呼び鈴**。単発＝一回巻き、繰り返し＝ぜんまい、合図＝呼び鈴。

**全員がゴールに集まる理由**: ゴールは**撮影台**。ジオラマが完成したら、試し人形を全員並べて記念写真を撮り、作品帳に貼る。1人欠けたら写真にならない。クリア画面がそのまま写真になる。

**トーン・色・素材**: 午後の作業場。木・方眼紙・付箋・未塗装のパテ。
`#f3eedf` 方眼紙／`#c89b6d` 作業台の木／`#d9d2c5` 未塗装のパテ／`#84bd5f` 塗装した草／`#f6d36b` 黄の付箋／`#b9d98a` 若葉の付箋／`#5a4a3f` 鉛筆／`#e0644f` 禁止の付箋（禁止にだけ）

**音楽**: 小さな室内楽（ピチカート・クラリネット・ファゴット。いまのタイトル曲 B5/B6 の方向）。作業場は時計と木の音。

**物語の伝え方**: 付箋の一言、作業台に残された設計図、棚の写真。模型師本人は最後まで出さず、手書きの文字だけで人柄を見せる。

**進行とメタ**: クリアしたジオラマは小さく縮んで棚に飾られる（**島の地形をそのまま縮小して使えるので安い**）。作品帳に写真が増える。

**強み**: ブロックの見た目・ハブ・全員ゴール（写真）・クリア画面が一つの理屈でつながる。島の縮小模型は資産の再利用になる。
**弱み・危険**: 「人形が動く」「小人と大きな机」は広く使われた題材で、既存作品と比べられやすい。試験・検品の言葉が冷たく感じられるおそれ。巨大な机の小物（鉛筆・定規）が必要。
**制作費**: 中。ハブの巨大な小物が数点要るが、島の縮小は再利用できる。

**島の名前（案）**: 試作その一「段差」／谷の模型／回し試験台／丘の情景／巣の情景（未塗装）／石切り場のジオラマ／ぜんまい仕掛けの尾根／付箋だらけの庭／三つの呼び鈴／崩れた城の模型／吊り下げの浮島（上から糸で吊った島）／大作「遠征」

## 案D　とどけ便 — 「差出人は、いつまでも差出人。」

- **仮題**: 『とどけ便』／英 *Relay Post*（作業用リポジトリ名に近い）
- **一行**: 「できる」を小包にして島から島へ届ける配達組合の新人たちが、届け合いで道をひらく。

**舞台と島がある理由**: 島々は郵便の航路でつながっていた。航路が途絶えた島では、届くはずの「できる」が止まり、橋も昇降台も動かない。

**ハブ**: **本局**の仕分け場。壁の大きな航路図に、つながった島から線が引かれる。入口は島ごとの郵便受け。

**能力が貸せる理由／禁止の札**: 「できる」は**差出人札の付いた小包**。台帳の仕組みがそのまま配達の言葉になる: 出自＝差出人（変わらない）、付与先＝届け先、運び中＝配達中、直前の付与者＝前の配達人、単発の返還＝**返送**、付与者がいないとき＝**置き配**。禁止は**止め印**（赤い判）。判が押された物は、中身があっても動かない。

**プレイヤー・生き物・鐘**: プレイヤーは**新人配達員**。生き物は**宛先の住人**で、頼んだ物の使い方は本人の自由。鐘は**集配の鐘**で、鳴っている間だけ動く荷がある。発射台は**速達筒**。

**全員がゴールに集まる理由**: ゴールは**島の局**。配達員全員が局に戻って「配達完了」の判を押すと、その島の航路が開く。

**トーン・色・素材**: 港町の朝。帆布・木箱・封蝋・切手。
`#e9dcc3` 帆布／`#b98a5e` 木箱／`#6f9e64` 切手の緑／`#edc36a` 荷札の黄／`#cde3ea` 朝の空／`#4d3a2c` インク／`#e0644f` 止め印（禁止にだけ）

**音楽**: 軽快なフォーク＋ブラス少し（遠くの汽笛は低く）。局の中は判の音と木箱の音。

**物語の伝え方**: 荷札の宛名・航路図・届かなかった手紙の山。最後の島では、自分たち宛ての手紙が届く。

**進行とメタ**: 航路図に線が増え、本局のまわりに町ができていく。

**強み**: 能力の台帳（ADR 0005）が配達の言葉に完全に重なり、ルールの説明が楽になる。リレー（受け渡し）という核がタイトルに直結する。
**弱み・危険**: 配達は「作業」の印象が強く、ゆるふわの温かさが出にくい。配達を題材にした有名作が多い。
**制作費**: 小〜中。木箱・郵便受け・判・航路図など単純な形が多い。

**島の名前（案）**: はじめての預け便／谷越えの速達／回覧の段／丘の上の郵便受け／迷子のお届け／石切り場の重い荷／風便の尾根／止め印の庭／三つの集配鐘／砦跡の局留め／浮島航路／最果て便

## 推奨: 案A「もちより島」

1. **ゲームの言葉を変えずに世界の言葉になる。** コードでも UI でも「器」と呼んでいる。器（うつわ）は日本語で食器のことでもある。単発＝ひとくち、繰り返し＝おかわり、範囲＝大皿、×n＝大盛り、F で回収＝下げる、禁止＝おあずけ。新しい用語を覚えさせず、知っている言葉で厳格なルールが読める。
2. **全員ゴールの理由が、説明なしで分かる。**「いただきますは、そろってから」は日本の誰もが知る作法で、協力の最後の瞬間がそのまま一番温かい場面になる。ゴールの窪み（ADR 0011 決定 10）は、作り直さずに掘りごたつの食卓として見せられる。
3. **禁止が罰ではなく作法になる。** 本人の「システムで妨害しない」と合い、標語「ルールは厳格に。解法は自由に。」も「作法は厳格に、持ち寄るものは自由に」と言い換えられる。
4. **今ある見た目と音がそのまま使える。** はちみつ色の木枠の能力ブロック、生成りと木の札の UI、フォークの BGM 候補（B1/B2）、木を叩く効果音の方向。
5. **ハブの成長が安い。** 長卓の区画・座る客・料理の皿を足すだけで、進み具合が一目で分かる。客は島の生き物の再利用。
6. **途中参加や死亡観戦まで物語で言える。**「席はいつもひとつ空けておく」（途中入室は次の全員リセットで合流、ADR 0007）、「落ちたら湯気になって見守る」（死亡観戦）。

決めきれない点（本人しか答えられない）: 食べ物のモチーフを好むか、日本の言葉を前に出すか、海外向けをどれだけ重く見るか。下の質問で確かめる。

迷ったときの組み合わせ案: A を土台に、B の「クリアでハブの曲に楽器が一つ増える」、C の「クリア画面を全員の記念写真にする」を借りられる（世界観を濁さない範囲で）。

## 本人に決めてほしいこと（これだけで1つに絞れる）

1. **いちばん大事にしたい気持ちはどれか**: いっしょに食べる（A）／いっしょに鳴らす（B）／作って試す（C）／届け合う（D）。
2. **食べ物のモチーフはよいか**（A のときだけ）。料理を作る遊びは入れない前提。
3. **日本の言葉・作法を前に出すか、無国籍に寄せるか**（おあずけ・いただきます・のれん・掘りごたつ）。
4. **物語の量**: ほぼ無言（看板1行と記号だけ）でよいか、短い台詞の住人を置くか。
