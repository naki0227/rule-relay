## 2. 教える順番（変えた後）

1 つの場面で新しいことは 1 つ。その場面では新しいことが先へ進むただ 1 つの方法になる安全な場所を先に置き、
そのあとに少し難しい使い方を置く。どのステージも「新しい仕掛けか新しい組み合わせ」の性格は変えていない
（[campaign-plan.md](campaign-plan.md)）。

| # | 基本の操作 | どこで | ステージでの教え方 | 案内（キーの絵と言葉） | 消える条件 | 確かめるテスト |
|---|---|---|---|---|---|---|
| 1 | 歩く・カメラ | 広場の出現地点 | 正面 6 m に導入のポータル。光の柱が立つ | [W/A/S/D] 歩く → [マウス] 見回す（1 つずつ） | 少し歩く・半周見回す | `test_first_timer` |

## 3. 案内の決まり（`src/ui/teach_hints.gd`）

- 出すのは**いちばん要る 1 つだけ**。2 つ以上は重ねない（前は最大 4 つ並んだ）。
- 選ぶ順（上ほど急ぐ）: その場の動作（入口・拾う）→ 貸した単発を使う → 取り戻す → 鐘 → 投げる（遠くを狙った）→ 動物に移動をあげる →
  ステージの教える場所 → 渡す（選ぶ）→ 装備 → 保存 → 足もとの禁止 → 段差でジャンプ → 歩く・見回す →
  （目安の時間を過ぎたら）やり直し・メニュー。
- ステージに入った直後に目的の札（`ObjectivePanel`）が大きく出ている 3 秒は、案内を出さない（目的の札と重ねない）。
  書体・色・キーの絵は目的の札と同じ `UiTheme`。
- **教える場所**（`StageDef.HintSpot`）: ステージを作る人が「ここに来たら、この案内」を置ける。円の中にいて、まだ慣れていない
  ときだけ出る。`while_holding` を付けると、そのブロックに能力が付いている間だけ（1-2 の台は、取った後は出さない）。
- 慣れたかの記録は今までどおり `HintMemory`（遊ぶ人の記録の名前ごと、3 回で慣れる）。協力中も各自の画面と記録で、
  ほかの人の操作では消えない。
- 記録の名前と、数える場所（`PlayerInput`）:

| 記録 | 数えるとき |
|---|---|
| `move` / `look` | 歩いた時間・回した角度（今までどおり） |
| `jump` | 床から自分で跳んだ（貸した単発が無いとき） |
| `select` / `lend` / `fire` / `range` / `throw` / `vote` / `menu` / `save` | 今までどおり |
| `recall` | 能力の付いた物を F で取った（今までどおり） |
| `ban` | 禁止の付いた物を F で取った |
| `push` | 貸した W/A/S/D の単発を使った |
| `jump_then_move` | 空中のブロックへ W/A/S/D の単発を使った（予約） |
| `ground` | 地形のセルに渡した（触る・範囲） |
| `mode` | 方式を繰り返しに切りかえた |
| `creature_move` | 動物に移動を渡した（今までどおり） |
| `equip` | 装備を身につけている（状態から数える） |

## 4. F で取った能力はホットバーへ（`WorldLending.to_hotbar_if_free`）

ブロック・生き物・地形に最初から付いていた（だれの器にも入っていなかった）能力・禁止を F で取ると、ホットバーに空きが
あればそこへ入る（Minecraft と同じ）。前はかばんに入り、E で開いて並べないと使えなかった（F を教える 1-2 で止まる原因）。
変えたのはここだけ:
- 自分の器の能力は、今までどおり器へ戻る。仲間の器の能力は、今までどおり器なしで持つ。
- ~~落ちている器を拾ったときは、今までどおりかばんへ。~~ **2026-11-23 本人の判断「ホットバーに入れる」で、落ちている器も
  空きがあればホットバーへ**（ADR 0021 の 1。装備は身につけずに入れ物のまま、重い・浮く・泳ぐはかばんへ）。1-3 の頂の
  ジャンプも拾うとホットバーに入り、W1 でかばんを開く場面は無くなった。W1 のジャンプ・予備の S をブロックに付けて置く形は
  そのまま。
- F で取った・拾った能力が新しくホットバーに入ったら、その枠を選ぶ（2026-11-23。1-2 で取った直後に W を選んだままだった）。
- 持っているだけで効く性質（重い・浮く・泳ぐ。ホットバーに置くと勝手に効く）は、かばんへ。
ルール（台帳）は変えていない（GameWorld が取った直後にホットバーへ移すだけ）。協力中も、ホストが取った人の手元で同じにする。

## 5. 広場（最初の起動の流れ）

タイトル → 広場 → 1-1 の流れは今までどおり（出現地点の正面 6 m に導入のポータル、「歩く」「見回す」の案内）。
足したのは W1 のポータルの案内だけ: **W1 で次に遊ぶポータル**（開いていて、まだクリアしていない最初の枠）に、
夕日色の柔らかい光の柱を立てる（巣の柱と同じシェーダー。カメラから 3 m で消え、9 m ではっきり）。門の上の文字は、
最初の門が「はじめはここから」、次からは「つぎはここ」。W1 を全部クリアしたら柱は立たない。
タイトル・メニュー・HUD・カメラは別の作業（最初の 10 分の見直し）の担当なので触っていない。

## 6. 足りない点・本人に聞きたいこと

- **繰り返し（4）を、ひとりで必ず使う場面は作れなかった**。この作品のルールでは、単発は押すたびに 1 回動いて戻り、
  押すのに距離の制限が無いので、ひとりなら単発で代わりができる（繰り返しが要るのは協力のエレベーターや、届かない所で
  動き続けさせたいとき）。なので W1 では「見せる（はねる台）」と「違いで困る（石が滑る）」までにした。
  切りかえの [Q] の案内も出していない（要らない場面で出すと、本人の「必要な瞬間だけ」に反する）。
- 受け入れた技（重ね跳び・どの地面のセルも持ち上げ台・ダッシュ）があるので、高さの関所は「その方法しか無い」には
  できない。必ず要るのは、1-2 の F（ジャンプが無い）、1-3 の石と動物（動物の道）、1-5 の投げる（幅 14 の空）。
  装備（1-5）と禁止（1-6）は、いちばん分かりやすい道の上に置いて案内を付けたが、別の道でも解ける。
- 1-5 にはダッシュが落ちている（教えるのは 3-1）。受け入れた技のテストが使うので残した。
- 数値（幅 14・光の柱の 3〜9 m・案内の円の半径）はすべて仮。
