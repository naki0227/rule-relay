## 確認したこと

| コマンド | 結果 |
|---|---|
| `tools/check.sh --build`（Linux、Godot 4.6.3） | 成功。format / lint / import / static / テスト 52件 / 180フレーム起動 / Windows exe 出力 |
| GitHub Actions（PR #1） | 成功。Linux の品質ゲートと、Windows ランナーでの exe ヘッドレス起動 |
| 反例: 禁止の優先を外す / 単発を常に成功にする / 単発の禁止判定を飛ばす / 空中の段差補助を戻す | それぞれ対応するテストが失敗することを確認し、元に戻した |
| ソフトウェア描画のスクリーンショット（`tools/capture_screenshot.gd`） | `docs/images/p0-range-repeat.png`（範囲・繰り返しで左右だけ跳び、中央の禁止ブロックは残る） |

結合テストで再生した高台への解法（いずれもヘッドレスで成功）:

1. 跳ねるブロックの「ジャンプ禁止」を拾い、自分は跳べないまま、跳ね始めたブロックに乗って高台へ
2. 並んだブロックの1つにジャンプを単発で渡し、Space で跳ばして乗る
3. ブロックに W を繰り返しで渡して岩棚の前まで運び、W を回収して階段にして登る

あわせて「何も渡さなければ、壁に沿って跳び続けても届かない」ことをテストした。

## 見つけた不具合と対処

- 段差補助が空中でも働き、壁の上面へ登れていた（企画書 4-6 の「ワープしない」に反する）。床に立って歩いているときだけ働くように直し、高さ 1.6 の壁へ空中から登れないことをテストに追加した。島のテストだけではこの不具合を検出できなかったため、専用のテストにした
- 初期コミットに gdlint の既定設定ファイル `gdlintrc` が混入し、`.gdlintrc` より優先されていた。削除した
