## rule-relay v0.3.1（試遊版）

はじめの草原（ワールド 1）で操作を 1 つずつ覚えられるようにし、最初の 10 分のわかりにくいところを直した版です。目安の時間・難しさ・見た目は、引き続き仮です。

### はじめの草原で、操作を順に覚えられるように
- **新しいことは 1 回に 1 つだけ。** その操作をしないと先へ進めない場所で、1 つずつ覚えられるようにしました。

  | 覚えること | 場所 |
  |---|---|
  | ジャンプ・ブロックに渡す | 1-1 |
  | F で取る | 1-2 |
  | 繰り返し・ブロックの W/A/S/D・動物 | 1-3 |
  | 地面に渡す・範囲 | 1-4 |
  | 投げる・装備 | 1-5 |
  | 禁止 | 1-6 |

- **変えたステージ**
  - **1-2 みんなで回す:** 作り直しました。スタートの前の台のジャンプを F で取って進みます。
  - **1-5:** 遠くの小島に、投げてしか渡せない動物を足しました。
  - **1-6:** 床の石にジャンプ禁止が付きました。
- **ヒント:** 同時に 1 つだけ、必要なときだけ短く出ます。同じ操作を 3 回すると消えます。協力プレイでは人ごとに数えます。
- **最初のポータル:** 広場では、次に遊ぶポータルにオレンジの光の柱が立ち、「はじめはここから」「つぎはここ」と出ます。

### 操作しやすく
- **取った能力・拾った能力は、空いていればホットバーに入ります**（いっぱいのときはかばん）。入ったら自動で選ばれるので、かばんを開かなくてもすぐ使えます。重い・浮く・泳ぐは、体にすぐ効くので、今までどおりかばんに入ります。
- **見上げても、カメラが地面にもぐりません。** 段の真下からでも、縁のセルを狙えます。
- **貸した単発を W/A/S/D で動かした瞬間は、自分は歩きません。** 崖の縁で石を押しても、自分は縁に寄りません。押し続けると歩きます。
- **広場に戻ると、次に行くポータルが見える向きになります。**
- **近づいても、ポータルの名前・名札・動物の吹き出しが画面いっぱいに大きくなりません。**

### 表示と言葉
- お知らせの言葉を、ヒントと同じにそろえました（「ジャンプを渡しました（単発）」「取り戻しました」など）。
- クリアの表示を「クリア！＋ステージ名」にしました。内部の名前や「（仮）」は出ません。
- ひとりで遊ぶときは、協力プレイ用の言葉（全員の投票・全員復活など）を出しません。
- タイトルの「友だちと遊ぶ」の中に、IP・ポートの項目をしまいました。

### 遊び方
- 試遊版なので、ステージと地域は最初から全部開いています。製品と同じ開き方で遊ぶときは、起動の引数に `-- --campaign` を付けてください。
- 詳しい手順は `docs/how-to-test.md` にあります。
- アプリの版は 0.3.1 です。

### Windows で起動できないとき
exe はコード署名をしていません。Windows 11 で「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください。
「スマート アプリ コントロールでブロックされました」と出る PC では、起動できません。詳しくは ZIP の中の `README_Windows.txt` を見てください。
