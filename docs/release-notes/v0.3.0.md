## rule-relay v0.3.0（試遊版）

v0.2.0 の試遊で「やりにくい」「何をすればいいかわからない」と感じた点を、まとめて直した版です。外部レビューで見つかった点の直しも入っています（`docs/reports/2026-11-21-v0.2.0-review.md`）。目安の時間・難しさ・見た目は、引き続き仮です。

### 何をすればいいか、わかるように
- **ステージに入ると、目的が出ます。** 「どうぶつを巣へ」「鐘を鳴らす」「ゴールへ」のように、クリアに要ることを 3 秒大きく出し、そのあと右上に小さく残します。できた項目にはチェックが付きます。Tab かメニューで、もう一度見られます。
- **巣の場所が見えるようになりました。** 巣には小枝の巣の模型と、遠くから見える光の柱があります（近づくと薄くなります）。巣ごとに色が違い、画面の外にあるときは端に矢印が出ます。
- **動物が、ふつうの動物らしく動きます。**
  - 今の能力で行けるところまで巣に近づき、足りない能力を吹き出しの中のメダルで見せて待ちます。たとえば W だけなら、壁の前まで来てジャンプのメダルを出します。
  - そこで能力を渡すと続きを進みます。願いが叶うと喜びます。
  - 動ける動物は、近くを少しぶらつきます。仕掛けのあるマスや崖には近づきません。

### 操作しやすく
- **床が抜けなくなりました。** 浮島に厚みができ、地面のセルに能力を渡して動かしても、浅いくぼみが残るだけです。
- **範囲で渡したブロックは、一緒に動きます。** 2×2 を右へ動かすと、すき間なく丸ごと動きます。
- **ブロックの W/A/S/D は「予約」になりました。** 空中や移動の途中でも、進む先が空いた瞬間に 1 マス動きます（ジャンプの後に前へ、など）。繰り返しでも同じです。
- **狙いが十字と合うようになりました。** これまでは十字の 0.6 m 左を狙っていました。十字の近くの物を拾う狙いの補助と、狙っている物の名前の表示も加えました。
- **「投げる」で、メダルを本当に投げます。** 腕で投げたメダルが弧を描いて飛び、当たった物（ブロック・動物・地面・仲間）に能力が付きます。何にも当たらなければ、手元へ戻ります。
- **範囲で渡したときの表示を、すっきりさせました。** 輪 1 つと印 1 つだけです。

### 禁止と装備
- **禁止は、そのブロックの上に立つ人と動物にも効きます。** ジャンプ禁止のブロックの上では跳べません。ダッシュ・W/A/S/D・登る・投げるも同じです。乗っている間、ホットバーの使えない能力は薄く表示されます。全部禁止のブロックからは、F で禁止を取り戻すか、リセットで出られます。
- **装備は、身につけたときだけ効きます。** 持ち物では、ブーツやグローブの見た目のまま並びます。ホットバーの装備から渡すと中の能力だけが移り、入れ物は残ります。F で回収すると、同じ入れ物に戻ります。身につけている装備は渡せません。
- **インベントリの操作を直しました。**
  - 開いても、検索欄に勝手に入りません。
  - マウスを乗せて 1〜9 を押すと、その番号のホットバーへ移ります。
  - クリックでつかみ、クリックで置けます。物があるところに置くと入れ替わります。ドラッグでも入れ替わります。

### ステージの出入りとメニュー
- **ステージを出ると、入ったポータルの前に戻ります**（クリアしたときも、途中で出たときも）。次に起動したときも、そこから始まります。
- **ステージ中のメニュー**は「つづける／チェックポイントからやり直す／このステージを最初から／このステージから出る／せってい／ゲームをやめる」になりました。
  - 「このステージを最初から」は、そのステージだけをやり直します。ほかのステージの進み具合や報酬は消えません。
  - 協力プレイでは、ホストが選ぶと全員がそうなり、参加者が選ぶと投票になります。

### 協力プレイ
- 参加者が Esc メニューの「ゲームをやめる」を選ぶと、部屋を出た扱いになります。まだクリアしていない回の報酬は、受け取れません。
- ホストがクリア前にやめた場合は、通信が切れたのと同じ扱いです。部屋が残っている間に同じ記録の名前で入り直せば、報酬が届きます。
- 広場の秘密の入口（寄り道のワールド）を見つけると、そのとき部屋にいた全員の進行に保存されます。

### 遊び方
- 試遊版なので、ステージと地域は最初から全部開いています。製品と同じ開き方で遊ぶときは、起動の引数に `-- --campaign` を付けてください。
- 詳しい手順は `docs/how-to-test.md` にあります。
- アプリの版は 0.3.0 です（Mac は「情報を見る」、Windows は exe のプロパティで見られます）。

### Windows で起動できないとき
exe はコード署名をしていません。Windows 11 で「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください。
「スマート アプリ コントロールでブロックされました」と出る PC では、起動できません。詳しくは ZIP の中の `README_Windows.txt` を見てください。

### 配布の ZIP
- Windows・Mac（署名と公証済み）・Linux のどの ZIP にも `LICENSES.txt` が入っています。Windows の ZIP には `README_Windows.txt` も入ります。
