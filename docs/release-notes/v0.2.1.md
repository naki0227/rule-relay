## rule-relay v0.2.1

v0.2.0 の外部レビューで見つかった点を直した修正版です（詳しくは `docs/reports/2026-11-21-v0.2.0-review.md`）。

### 遊ぶ人に関わること
- **Esc メニューの「ゲームをやめる」は、協力中の参加者では「部屋を出た」扱いになりました。** ホストへ退出を伝え、受け付けを待ってから（最長 2 秒）終わります。まだクリアしていない回の報酬は受け取れません。
- **通信が切れた人の報酬は、部屋が残っている間だけ守られます。** 部屋があるうちに同じ記録の名前で入り直せば届きます。全員が抜けて部屋が無くなった後は届きません。
- **広場の秘密の入口（寄り道のワールド）を見つけると、そのとき部屋にいた全員の進行に保存されます。** これまではホストの進行にだけ保存されていました。
- アプリの版が 0.2.1 になりました（Mac の「情報を見る」、Windows の exe のプロパティ）。

### Windows で起動できないとき
exe はコード署名をしていません。Windows 11 で「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。
「スマート アプリ コントロールでブロックされました」と出る PC では起動できません。詳しくは ZIP の中の `README_Windows.txt` を見てください。

### 配布の ZIP
- Windows・Mac（署名と公証済み）・Linux のどの ZIP にも `LICENSES.txt` が入りました。Windows の ZIP には `README_Windows.txt` も入ります。
