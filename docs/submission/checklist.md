`tools/check.sh --build` が `build/submission/rule-relay-windows.zip` と `rule-relay-macos.zip` を作り、`tools/check_submission.py` で中身を確かめる。CI でも毎回作り、`rule-relay-submission` という成果物に残る。

- [ ] 【自動】Steam が入っていない（Steam のコード・DLL・`steam_appid.txt`・印の文字列。`tools/check_no_steam.py` と同じ検査）。Steam なしで動く提出版（ソロと直接接続）
- [ ] 【自動】秘密のファイルが無い（`.env`・鍵・証明書・`export_credentials.cfg`）
- [ ] 【自動】user:// に書かれるもの（進行 `progress/`・設定 `settings.cfg`・合言葉 `session/`・案内の記録 `hints/`・ログ）と、`_sc_`・`override.cfg` が無い

- [ ] 【自動】`LICENSES.txt` が ZIP の一番上にあり、リポジトリの版と同じで、エンジンが報告する部品の一覧と食い違っていない

### 同梱するもの・しないもの（決めたことと理由）

| 入れる | 理由 |
|---|---|
| 実行ファイル（pck を埋め込んだ `rule-relay.exe` / Mac の `.app`） | 遊ぶのに要る最小限。1 つのファイルなので展開の失敗が起きにくい |
| `LICENSES.txt` | Godot（MIT）・組み込みの部品・OFL のフォントは、配るときに著作権表示とライセンス文を付ける条件がある。pck の中に入れても審査員は読めないので、ZIP の一番上に置く |

| 入れない | 理由 |
|---|---|
| `art/`（Blender の原本・生成スクリプト・Stable Audio の候補） | ゲームは書き出した `.glb`・`.wav` だけを読む。原本（2026-11-20 で約 16 MB）は審査に要らない（`art/` は `.gdignore` で元から書き出されない） |
| `tests/`・`tools/`・`docs/` | ゲームの実行に要らない。テストは CI で回し、結果は企画書 3.7 に書く。書き出しのプリセットで外す（`export_presets.cfg`） |
| ログ・user:// のデータ | 開発中の記録（記録の名前・合言葉など）が混ざると、他人の PC で前の状態から始まったり、情報が漏れたりする |
| 秘密（`.env`・鍵・証明書・Mac の署名の情報） | 漏れると取り消せない。Mac の署名は CI の Secrets にだけ置く（`docs/macos-signing.md`） |
| Steam 版（GodotSteam・Steam の DLL） | 審査員の PC に Steam を前提にできない。未発売の条件にも関わる（ADR 0006・0012） |
| Linux 版 | 対象プラットフォームはモバイルと PC で、提出は Windows と Mac にした。Linux（Steam Deck）向けは書き出せるが提出しない |
