## 2. 内容・面白さ

### 2.1 一言で言うと

自分の「操作」そのもの——前へ進む力、跳ぶ力、投げる力——を、**アイテムとして世界や仲間に貸し出す**パズル。
ブロックにジャンプを貸せばブロックが跳び、仲間にジャンプを集めればその仲間が高く跳ぶ。貸したあいだ、自分はその操作ができない。
ルールは厳格（能力は世界に 1 つずつしかなく、複製も消滅もしない。禁止は必ず優先される）だが、ゴールへの道は自由で、何通りもある。

### 2.2 核の仕組み【確定】

| 仕組み | 内容 | 根拠 |
|---|---|---|
| 能力は貸し借りできるアイテム | W/A/S/D・ジャンプ・投げる・ダッシュなどの操作が、1 つずつ「能力トークン」（画面ではメダル）になっている。器（アイテム）から能力だけを貸し出し、器は手元に残る。トークンは世界に 1 つで、複製しない | `docs/requirements-status.md` 7、ADR 0003・0005 |
| 貸す相手 | ブロック（地形のセルを含むどのブロックにも）・生き物・仲間。ブロックの W/A/S/D は世界の方角（W＝北）、プレイヤーはカメラから見た向き | requirements-status 4-1・4-2・5.1 |
| ブロックの移動は「予約」 | ブロックが空中や移動の途中でも、進む先が空いた瞬間に 1 マス動く（ジャンプの後に前へ、など） | v0.3.0 のリリースノート、`src/game/block_move_buffer.gd` |
| 範囲で貸す | 水平の円（半径 5 ブロック。仮の値、`BlockRules.DEFAULT_RANGE_RADIUS`）の中の全ブロックへ、1 つのトークンで一度に貸す。範囲で渡したブロックは一緒に動く（2×2 を右へ動かすと、すき間なく丸ごと動く）。どこからでも F で一括回収 | requirements-status 5.3、v0.3.0 のリリースノート、`tests/integration/test_group_move.gd` |
| 投げる | 腕で投げたメダルが弧を描いて飛び、当たった物（ブロック・動物・地面・仲間）に能力が付く。何にも当たらなければ手元へ戻る（本人 2026-11-21「実際に当たったところから付与にしてよ」） | ADR 0017 |
| 禁止 | 「ジャンプ禁止」のような禁止の札も、能力と同じように持ち運び・貸し借りできる。禁止は能力より必ず優先される（貸した単発も起動できない）。禁止の付いたブロックの上に立つ人と動物にも効く。外から押されて動くことは妨げない | requirements-status 4-4、TODO（2026-11-19 本人の確定）、v0.3.0 のリリースノート、`src/game/floor_bans.gd` |
| 集めると強くなる | 同じ能力を n 個持つと、ジャンプは高さ n 倍、W は速さ n 倍、投げるは射程 n 倍。上限は付けない | ADR 0011 決定 11（2026-11-20 本人） |
| 装備は「入れ物」 | ジャンプブーツ（高跳び）・クライミンググローブ（登る）など。身につけたときだけ効き、渡すと中の能力だけが移って入れ物は残る。F で回収すると同じ入れ物に戻る。身につけている装備は渡せない（本人 2026-11-21） | ADR 0018 |
| 体の性質の能力 | 重い（重さの板を沈める・風に流されない）・浮く（ゆっくり落ちる・水に浮く。ブロックに渡すと筏）・泳ぐ（水の中を進む）。持っているだけで効き、ほかの能力と同じく貸せて禁止もできる。数値は仮 | ADR 0015、`docs/campaign-plan.md`「能力の開放の予定」 |
| 願いを持つ動物 | 動物は命令できない。各ステージの動物が「高いところの巣へ行きたい」「鐘を鳴らしたい」などの願いを持ち、能力を渡すと願いに従って自分で使う。今の能力で行けるところまで巣に近づき、足りない能力を吹き出しの中のメダルで見せて待つ。巣には遠くから見える光の柱がある。禁止は願いより優先 | requirements-status 6、ADR 0016・0019（本人 2026-11-21「吹き出しの中に欲しいこういうメダルのやつ」） |

### 2.3 3 つの発動方式【確定】

ブロックに能力を貸すとき、いつ発動するかを選ぶ（`docs/requirements-status.md` 5.2）。

| 方式 | 動き | 返り方 |
|---|---|---|
| 単発 | 対応するキーで 1 回だけ試みる。貸した直後に勝手には動かない | 起動したら、発動できなくても（禁止・塞がれている・空中）発動したのと同じ扱いで、直前に貸した人へ自動で戻る（2026-11-19 本人の確定） |
| 繰り返し | 一定の間隔で自動で試み続ける（例: W と S を交互にして往復足場） | 手で回収（F） |
| 信号 | 鐘などの音が届いているあいだだけ発動し、途絶えると休む | 手で回収（F） |

### 2.4 ゲームサイクル

```
広場（オーバーワールド）を歩いて、ワープの門（ポータル）を見つける → 門に入ってステージ（開けた島）へ
  → 目的（鐘・動物を巣へ・ゴール）を見て、能力を貸す・集める・回して、全員でゴールに集まる
  → クリア報酬（見た目・記録・収集品）を各自の PC に保存 → 入った門の前へ戻る
  → 動物が広場に住み、建物が建ち、ワールドの最後をクリアすると次の地方への橋・階段が開く → 次の門へ
```

| 段階 | 内容 | 状態・根拠 |
|---|---|---|
| 広場 | 番号のメニューではなく、歩き回れる広場に門が並ぶ。真ん中の草原（W1）から、東・北東・西・北西・北・さらに北へ地方が広がる。地方は地形だけで開く（クリアで橋が架かる・岩がどく・階段がせり上がる。通せんぼのルールは足さない）。広場でも能力を使え、小さな仕掛けと秘密の庭・小島（寄り道のワールドの入口）がある | 【確定】本人（2026-11-21）の決定、ADR 0013、`docs/campaign-plan.md`。試遊版は最初から全部開いている（製品と同じ開き方は起動の引数 `-- --campaign`） |

### 2.5 ストーリー・世界観設定（目的と舞台）

決まっていること（本人の決定。ADR 0013、2026-11-21）:
- 雰囲気は「ゆるふわで温かみのある 3D ブロックの箱庭」。明るい昼・丸くてかわいい生き物・やさしく暴力のない世界。
- 物語は脇役。参考にした有名な作品からは何も写さない（キャラクター・UI・名前・物語の入口）。
- 各ステージの動物の願いを叶えると、動物が広場に住む（「閉じ込められた動物を救う」話にはしない）。

実装してあること（AI が作った。演出の中身は仮）:
- 最後のワールド「空の頂」の最終ステージ（7-6 頂の祭り）で、全員がそろってクリアすると、作ってある本編のステージの動物が並んで喜ぶお祝いが出る（`SummitFestival`、`docs/campaign-plan.md`）。

【未決・本人が決める】タイトル・物語・最終目的・主人公の設定は決まっていない（引き継ぎ仕様 2-4「世界全体の物語・最終目的は未決」）。
世界観の案は `docs/worldview/`（第 5 回まで。状態は「提案」で、本人はまだ選んでいない）にある。本人が選んだら、ここに次を書く。

### 2.6 セールスポイント（ならではの面白さ）

1. **自分の操作を手放す決断**: 貸せば世界が動き、自分は動けなくなる。「誰が・いつ・何を手放すか」が、そのまま協力の会話になる。
2. **ルールは厳格、解法は自由**【確定】: クリアは結果（島の条件と全員の到達）だけを見て、手順を強制しない（`src/stages/clear_condition.gd`、引き継ぎ仕様 2-5）。開けた島に道が何通りもあり、想定外でもルールに合った解き方は歓迎する。
3. **ひとりでも、4 人でも**: 同じ島を、ひとりなら装備や回り道で、協力なら能力を集める近道で解ける（ADR 0011 決定 2・8）。
4. **妨害をルールで止めない**【確定】: 下の 2.8。
5. **動物の願いを叶える**: 動物は命令できないが、能力を渡せば自分で巣へ向かい、足りない能力を吹き出しのメダルで教えてくれる。助けた動物が広場に住み、広場がにぎやかになる（ADR 0013・0019）。

### 2.7 新規要素/オリジナル要素

- 操作（W/A/S/D・ジャンプなど）を 1 つずつのトークンにし、世界のブロック・生き物・仲間へ貸し借りする。貸したあいだ自分はその操作を失う。
- 能力と同じ形で「禁止」も持ち運べ、禁止が常に優先される。禁止を手放すか、持ったまま別の道を探すかが選択になる（「札の庭」、ADR 0011）。
- 単発・繰り返し・信号の 3 つの発動方式と、音（鐘）を信号にした仕掛け。
- 1〜4 人の協力で、能力を集めると数だけ強くなる（上限なし）。それでも「全員がゴールに集まる」ので、集めた力を誰かが回す手間が残る（ADR 0011 決定 11）。
- 「投げる」は本当にメダルを投げ、当たった物に能力が付く。谷の向こうのブロック・動物・仲間へ能力を届けられる（ADR 0017）。
- 風・氷・水の流れ・重さの板・時の鐘・ワープの石などの仕掛けも、能力（重い・浮く・泳ぐ）と組み合わせて解く。どれも地形と持ち物で表し、遊びを止めるルールにはしない（ADR 0014・0015）。

### 2.8 協力のルール: 全員でゴールに集まる・地形で設計する【確定】

- **全員がゴールに集まる**（ADR 0011 決定 9、2026-11-20 本人）: どのステージも、島ごとの条件に加えて、生きている全員がゴールの箱に入ったらクリア。死亡観戦中・途中入室で待機中の人は要らない。ひとりなら「自分がゴールに着く」。
- **ルールではなく地形で設計する**（ADR 0011 決定 10、2026-11-20 本人「システム的に妨害するとかは絶対にしたくない。自由な発想を妨げるから」）:
  - 「ゴールの中からは渡せない」のような規則は足さない。
  - 代わりにゴールを縁より 1 段低い窪みにし、窪みの中からは下の仲間を狙いにくくした。渡したければ縁まで出ればよい（禁止はしない）。
  - 窪みから下の仲間への視線が地形で遮られることは、自動テスト（`tests/integration/test_goal_sightlines.gd`）で島ごとに確かめている。カメラを高く上げれば狙える場合があり、「難しくする」までで「できなくする」ではない。

### 2.9 1〜4 人のオンライン協力【確定】

### 3.3 プレイ環境の構築方法説明資料（2 次審査で使用。記載必須）

提出する ZIP は 2 つ（どちらも `tools/check.sh --build` で作り、`tools/check_submission.py` で中身を確かめる。`docs/submission/checklist.md`）。

| ZIP | 中身 |
|---|---|
| `rule-relay-windows.zip` | `rule-relay.exe`（ゲームのデータを埋め込んだ 1 つのファイル）、`LICENSES.txt`、`README_Windows.txt`（起動のしかた） |
| `rule-relay-macos.zip` | Mac のアプリ（`.app`、Intel・Apple シリコン両対応）、`LICENSES.txt` |

インストールは要らない。Steam・追加のランタイム・アカウント登録も要らない。

**Windows**
1. ZIP を展開して `rule-relay.exe` を起動する。exe はコード署名をしていない（有料の証明書は使わない方針。ADR 0001「欠点・リスク」）ので、Windows 11 では次の画面が出ることがある。ZIP の中の `README_Windows.txt` にも同じことを書いている。
2. 「Windows によって PC が保護されました」（SmartScreen）と出たら、「詳細情報」→「実行」を押す。または、展開する前に ZIP を右クリック →「プロパティ」→「許可する」にチェック →「OK」としてから展開する。
3. 「スマート アプリ コントロールでブロックされました」（Smart App Control）と出た場合、**スマート アプリ コントロールがオンの PC では起動できない**（「実行」のボタンは無い）。
   - 設定の場所: 設定 → プライバシーとセキュリティ → Windows セキュリティ → アプリとブラウザー コントロール → スマート アプリ コントロール。
   - Windows の版によっては、一度オフにすると Windows を入れ直さない限りオンに戻せない。オフにするかは使う人の判断に任せる。
   - オフにしない代わりの方法: 公式の Godot 4.6.3 エディターでプロジェクト（ソース一式）を開いて実行する。
4. 「部屋を作る」とき、ファイアウォールの許可を聞かれたら許可する。

**Mac**
1. ZIP を展開してアプリを開く。
2. 署名・公証済みの版なら、そのまま開ける。署名なしの版で「開発元を確認できません」と出たら、アプリを右クリック →「開く」（`docs/how-to-test.md` 0）。
   - 【未決・本人が決める】提出する Mac 版を署名・公証済みにするか（Apple Developer Program が要る。`docs/macos-signing.md`）。
3. 「部屋を作る」とき、受信接続の許可を聞かれたら許可する。

**ひとりで遊ぶ**: タイトルで「ひとりで遊ぶ」→ 広場の出現地点の正面にある導入の門の前で F。

**協力で遊ぶ（2〜4 人）**
1. ホスト: タイトルで「部屋を作る」（ポート 24565）。
2. 参加者: 「部屋に入る」で、ホストの IP アドレスとポート 24565 を入れる。同じ LAN ならそのまま、インターネット越しならホスト側で UDP 24565 のポート開放が要る。
3. 1 台で試すとき: 2 つ起動し、2 つ目は記録の名前を変えて `127.0.0.1` に入る。Windows と Mac の組み合わせでもつながる（ゲームの版はそろえる）。

【未決・本人が決める】審査員が 1 人で協力プレイを確かめる方法の案内（1 台で 2 つ起動する手順を載せるか）。
