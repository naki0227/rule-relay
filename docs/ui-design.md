# UI の設計（2026-11-18、仮）

方針と出典は `docs/ui-research.md`（AAA タイトルの調査）。値は `src/ui/ui_theme.gd` の1か所で決める。
世界観・物語は未定なので、色と書体は仮のトークン。決まったら差し替える。

## トークン

| 役割 | 値 | 使う所 |
|---|---|---|
| 文字 TEXT | `#f3efe6`（温かい白） | 本文・見出し |
| 補助 TEXT_DIM / TEXT_FAINT | TEXT の不透明度 0.64 / 0.38 | 説明・使えない項目 |
| 線 LINE / LINE_STRONG | 白の不透明度 0.16 / 0.34 | 1px の枠・区切り |
| 面 SURFACE / SURFACE_SOLID | `#0e1016` の不透明度 0.62 / 0.88 | ホットバーの枠・円形 UI |
| 暗幕 SCRIM | 不透明度 0.58 ＋ぼかし | メニューの背景 |
| 強調 ACCENT | `#e2c07a`（金。器のアイコンと同じ系統） | 選択・貸出中・英字ラベル・知らせの線 |
| 警告 ALERT | `#e4574e` | 禁止の印だけ |

- 書体: Noto Sans JP（OFL、可変ウェイト）。Display 46/700、HeaderLarge 34/700、Header 24/700、Strong 18/500、Caption 15/400、Kicker 13/600（字間 2・金）。
- 角丸 4px、線 1px、余白は画面端から 56px（タイトルセーフに近い）。
- 文字には弱い影（下に 2px）。箱の代わりに、文字が集まる所だけ端から暗がりを敷く（下と左）。
- 動き: ease-out、FAST 0.15 秒・NORMAL 0.22 秒。
- 解像度: 1920×1080 を基準に、`canvas_items` / `expand` で拡大縮小する。

## 画面

| 画面 | 構成 |
|---|---|
| 通常の HUD | 照準（点。届くブロックでは金の輪）、照準の下に文脈の案内（[左クリック] 渡す / [右長押し] 範囲 / [F] 回収 / [F] 保存）、左に知らせ、下中央にホットバーと選んだ器の名前、その右に方式と届き方（[Q] [C]）。ホットバーは4秒操作が無いと薄くなる |
| 円形 UI | 暗いリングを3区画に分け、選んでいる区画を金で満たす。中心に方式の説明 |
| 持ち物（E） | 全画面ぼかし。左に「INVENTORY / 持ち物」、種類のタブ（金の下線）、下線だけの検索欄、一覧。右に選んだ器の大きなアイコン・名前・状態・説明。下に操作の帯 |
| 一時停止（Esc） | 全画面ぼかし。左に「PAUSED / 一時停止」と、文字だけの項目（選ぶと左に金の線）。右に説明。下に操作の帯と保存の数 |
| 到達 | 画面の帯に大きな文字と、左右の金の線（箱なし） |

## 確認方法

ゲームと同じ Forward+ で、ソフトウェア描画（lavapipe）により 1920×1080 で撮った（`docs/images/ui-*.png`）。Windows 実機の GPU とほかの解像度では未確認。
