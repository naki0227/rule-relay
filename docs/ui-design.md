# UI の設計（2026-11-18、仮）

## 方針

本人の指示（2026-11-18、3回目）にもとづく。参考の世界観は「ゆるふわで温かみのある3Dブロックの箱庭」。

- 景色とキャラクターを主役にする。UI は「生成りの紙と木の札」の素材感で、静かに添える。
- 明るく、柔らかく、親しみやすい。かわいいが、子ども向けに寄りすぎない。PC の製品版として違和感のない仕上げにする。
- 見た目は優しくても、能力・禁止・貸出のルールは、色と形の両方ではっきり示す。
- 既存作品の UI・キャラクター・アイコンは真似しない。記号はこのゲームの言葉（貸す・触る・投げる・1回・くり返し・音）から描く。
- 避けること:
  - 無機質な灰色の半透明パネル
  - SaaS のダッシュボードのような画面
  - タブ＋文字の一覧＋詳細だけのインベントリ
  - 過剰なグラデーションや装飾
  - 小さすぎる文字
  - 常に出ている操作説明の山

変更の経緯は `docs/ui-research.md` の最後にある。

## トークン（`src/ui/ui_theme.gd` の1か所で決める）

| 役割 | 値 | 使う所 |
|---|---|---|
| 地 CREAM / CREAM_DEEP | `#fff8ec` / `#f4e7d1` | パネル / 枠（スロット）の地 |
| 枠線 EDGE / EDGE_DEEP | `#e2cdac` / `#cdb38b` | すべての線（2px） |
| 文字 INK / INK_SOFT / INK_FAINT | `#4d3a2c` / `#8a7462` / `#b7a28e` | 本文 / 補助 / 使えない（こげ茶。真っ黒にしない） |
| 選択 SUN | `#f09a45`（淡い地 `#fde3c6`） | 選択中の枠・照準の輪・メニューの項目 |
| 有効 LEAF | `#76a85f` | 自分に効いている能力の点・見出しの印・絞り込み |
| 貸出中 HONEY | `#e2a72e` | 貸出中の帯・状態 |
| 禁止 BAN | `#e0644f` | 禁止の輪と斜線（小さな印だけ） |
| 影 SHADOW | 茶の透明度 0.18 | パネルの影（黒く濁らせない） |

- 書体: Zen Maru Gothic（OFL）。本文は Medium、見出し・選択中・ボタンは Bold。文字の大きさは 18 / 21 / 26 / 34（1080p）。1280×720 でも最小 12px 相当。
- 形:
  - 線はすべて 2px（選択中だけ 3px）
  - 角丸は、パネル 22〜28、枠 14、チップ・吹き出しは全丸、キー 8（下辺だけ 4px）
- 動き: ease-out。選ぶ・開くは TRANS_BACK で少し弾ませる（0.14〜0.22 秒）。
- 1920×1080 を基準に `canvas_items` で拡大縮小する。

## 画面

### 持ち物（E）

| 領域 | 内容 |
|---|---|
| 上 | 題「持ち物」、小さな絞り込みのチップ（すべて・能力・禁止・貸出中）、検索欄。タブは画面の主構造にしない |
| 左 | キャラクターと装備の枠（頭・体・手・足。装備品は P2 で実装するので、いまは空） |
| 中央 | かばん（通常インベントリ。無制限で、7列のスクロールするグリッド）。件数を表示する |
| 右 | 選んだ（または指した）アイテムの大きなアイコン・名前・状態・場所・短い説明、その下に貸し出し中の一覧 |
| 下 | ホットバー9枠と、短い操作の一行（ドラッグで入れかえ · 1〜9 でホットバーへ · X でかばんへ） |

- 同じ器を複数の場所に出すとき（貸し出し中の一覧、検索で見えるホットバー）は、複製せず同じ器 ID を参照する。
- 移動は、ドラッグ＆ドロップ（かばん ↔ ホットバー、ホットバー同士の入れかえ）か、選んで 1〜9 / X。

### HUD

- 下中央: 生成りの台に載せたホットバー。選んでいる枠は少し大きく浮き、ほかは控えめにする。選び替えたときだけ、名前の吹き出しが出る。
- ホットバーの右: 発動方式と届き方の記号。切り替えた直後だけ、名前の吹き出しが出る。
- 照準の右下: 狙ったブロックやチェックポイントに応じた操作の案内。慣れたら出なくなる。
- 左上: 短い知らせ（最大3件、ふわっと消える）。
- ブロックの上: 器のアイコン（能力・禁止）と短い方式名だけ。付与先の輪郭は赤系（企画書 8）、狙っている輪郭は夕日色。
- 到達: 生成りのカードが上に小さく出て、4秒ほどで消える。
- 右上: ステージの目的（ADR 0018）。行ごとに印・短い文・チェック（そろうと若葉色）。入った直後だけ上の真ん中に大きく3秒出してから隅へ縮む。Tab（L スティック押し込み）と一時停止のメニューでもう一度大きく出る。広場では出さない。

### 一時停止（Esc）

景色を軽くぼかして生成りを薄く重ね、左寄りにカードを1枚出す（ステージの中では、その右にステージの目的を大きく出す。項目に「広場へもどる」が増える）。選んでいる項目は夕日色の縁になる。項目の説明は、カードの中で選んでいる項目の下に短く出す。保存の数は題の横に小さく出す。保存できない理由は、F を押したときに知らせで出す（常時は出さない）。

## 確認方法

ゲームと同じ Forward+ を、ソフトウェア描画（lavapipe）で 1920×1080 と 1280×720 の両方で撮った（`docs/images/compare/`）。変更前と変更後を並べた画像は `compare-*.png`。Windows 実機の GPU では未確認。
