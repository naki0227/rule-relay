## 前提にしたこと

ゲームの中身（このリポジトリの文書で確かめた）:

- 能力（W/A/S/D・ジャンプ・投げる・ダッシュ・登る・重い・浮く・泳ぐ）は、器に入った**メダル**。ブロック・地形・動物・仲間に貸して、F で取り戻す。器は手元に残り、メダルだけが動く（`docs/submission/proposal-draft.md` 2.2、`docs/release-notes/v0.3.0.md`）。
- 禁止も貸し借りでき、能力より必ず強い。禁止のブロックの**上に立つ人と動物にも効く**（v0.3.0）。
- 1〜4人の協力。ステージは全員がゴールに集まってクリア。
- ふわふわの浮島のブロックの箱庭。歩ける広場（ハブ）からポータルでステージへ入る。**願いを持つ動物**（高いところの巣へ行きたい、など）を巣へ届けると、その動物が広場に住み、建物が建って広場が育つ（`docs/campaign-plan.md`）。
- 標語は「ルールは厳格に。解法は自由に。」（タイトル画面に出ている）。

本人の好み（`docs/worldview/README.md`・round2〜round5 の本人の答えから。AI の読み取りを含む）:

- ゆるふわで温かい、ブロックの箱庭。子ども向けに寄りすぎず、PC の製品版らしい仕上げ。
- 日本の文化を題材にしない（第4回の答え「日本要素全くなくしてもいいよ」）。和紙の地図のような見た目も外れ。「人が消えた」のようなつかみも使わない。
- 物語はサブ。
- 既存の作品の名前・キャラクター・つかみをまねない。

このため、タイトルは「仕組み（貸す・回す・メダル）」「動物と願い」「浮島と温かさ」から作り、物語や文化に頼らないものにした。日本語の案も、文化ではなく**話し言葉**（渡すときのひとこと）から作っている。

商標の危険は、公式のデータベース（J-PlatPat・USPTO・TMview・WIPO）をこの環境から検索できなかったため、集約サイト・Web 検索・ストアの検索による**暫定**の判定。法的な助言ではない。本人が手で確かめる手順は [trademark-search.md](trademark-search.md) の「本人が手で確かめること」。

### 推奨: Hand-Me-Up の理由

1. **仕組みと目的が一語に入っている。** hand（手渡す＝能力を貸す）と up（1段ずつしか跳べない動物を高い巣へ上げる）。説明の文章がなくても、画面を見れば題名の意味が分かる。
2. **既存の言い回しを裏返した造語で、覚えやすいのに同名がない。** hand-me-down（お下がり）を知る人は一度で覚え、知らない人にも「Hand」「Up」の2語で伝わる。
3. **トーンが合う。** 少しとぼけた響きで、ゆるふわの箱庭と協力のにぎやかさに合う。日本文化にも物語にも寄らない。
4. **副題で日本語を足せる。** 「ハンド・ミー・アップ ― ちからを貸して、巣まで届けて」のように、日本の審査員向けには副題で補える。

弱み・危険: 日本語では「ハンドミーアップ」と8音でやや長い。hand-me-down を知らない人にはしゃれが伝わらない（意味は伝わる）。ハイフンの有無（HandMeUp／Hand Me Up）で検索が割れるので、表記を1つに決める。

### 本人に決めてほしいこと

1. **英語の題名か、日本語の題名か。** 提出はコンテスト（日本）で、配信は Steam（海外も）の予定。英語の題名＋日本語の副題（推奨）か、日本語の題名＋英語の表記か。
2. **仕組みを前に出すか（Hand-Me-Up・Lendlings）、動物と広場を前に出すか（Wishnest）。**
3. 上位5案のどれも合わなければ、気に入った言葉の向き（例: 「渡す」「巣」「浮島」）だけ返してもらえれば、その向きで作り直す。
