# タイトル候補の商標調査（予備調査）

- 状態: **予備調査**（2026-11-22、AI＝Claude Code が実施）。タイトルは未決定で、決めるのは本人。候補の一覧と意味は [README.md](README.md)。
- **これは法的な助言ではない。** 公式の商標データベースはこの環境から検索できなかった（下の「方法」）。ここにある商標の情報は、Web 検索で見つかった集約サイト（Justia Trademarks など、USPTO のデータを写したもの）の内容で、最新の状態とは限らない。出願や公開での使用の前に確実さが欲しければ、**弁理士に調査（類否判断を含む）を頼む**ことを勧める。
- 出願・登録・問い合わせは何もしていない。検索の結果はデータとして読んだだけ。検索に本人の個人情報は入れていない。

## 方法

### 調べた区分（ニース分類）

- 第9類（ゲームのプログラム、ダウンロードできるゲーム）
- 第28類（ゲーム、おもちゃ）
- 第41類（娯楽、オンラインのゲームの提供）
- ほかの区分でも、広く知られた名前で混同されそうなもの（例: 小売りのキャンドゥ）

### データベースごとの到達状況

| データベース | 結果 | 理由 |
|---|---|---|
| J-PlatPat（日本） | **検索できなかった** | JavaScript で動く画面で、取得できたのは「Loading...」だけ。公開の API はない |
| USPTO Trademark Search（米国） | **検索できなかった** | 画面は JavaScript だけで中身が出ない。裏側の検索の口は AWS WAF の確認付きで、それを迂回して呼ぶことはしなかった |
| TMview（欧州ほか多数の庁） | **検索できなかった** | JavaScript で動く画面で、中身が出ない |
| EUIPO eSearch | **検索できなかった** | 接続できなかった（タイムアウト） |
| WIPO Global Brand Database | **検索できなかった** | 人の確認（ALTCHA）の画面が出て、結果が出ない |
| Justia Trademarks（USPTO の写し） | 直接は取得できなかった | Cloudflare の確認画面。Web 検索の結果に出たページの内容だけを使った |
| Web 検索（英語・日本語） | 実施 | 商標の集約サイト（Justia・Markinton・TrademarkDir など）と、会社の公開資料を拾った。網羅的ではない |
| App Store | 実施 | Apple の公開の検索 API（iTunes Search API）で、米国と日本のストアを検索 |
| Google Play | 実施 | ストアの検索ページ（日本・日本語）を取得して名前を読んだ |
| Steam | 実施 | ストアの検索 API（`store.steampowered.com/api/storesearch`）。名前の部分一致に弱く、小さな作品を落とすことがある |
| itch.io | 実施 | サイトの検索ページを取得して名前を読んだ |

**つまり、公式の商標データベースは1つも検索できていない。** 商標の行の判定は「集約サイトと Web 検索で見つかった範囲」の暫定で、下の「本人が手で確かめること」を済ませるまでは確定しない。

### 危険度の決め方

- **高**: 同じか、ほぼ同じ名前が、ゲームに近い区分で生きている（登録・出願中）、または広く知られた名前と混同されそう。
- **中**: 似た名前が近い区分にある、同じ名前が別の分野で使われていて検索や印象で混ざる、または調べられなかった部分が大きい。
- **低**: 見つかったのは区分も意味も離れたもの、または死んだ（取り消し・放棄）ものだけ。

## 本人が手で確かめること

ブラウザで開いて検索する。どれも無料で、登録はいらない。結果はスクリーンショットか、番号を控えておくと弁理士に渡しやすい。

### 1. J-PlatPat（日本）— 最優先

- URL: <https://www.j-platpat.inpit.go.jp/t0100>（商標検索）
- 「検索項目」を **「商標（検索用）」** にして、次の語を1つずつ入れる。表示を「登録・出願中」の両方にする。
  - `ハンドミーアップ`、`HANDMEUP`、`HAND ME UP`
  - `レンドリングス`、`LENDLINGS`、`レミングス`、`LEMMINGS`
  - `ウィッシュネスト`、`WISHNEST`
  - `キャンドゥ`、`CANDO`、`CAN DO`、`キャンドゥアイルズ`、`できるの島`
  - `もってって`、`持ってって`、`モッテッテ`
- 次に検索項目を **「称呼（類似検索）」** にして、同じカタカナの読みで検索する（似た読みの登録が出る）。
- 「区分」に **9・28・41** を入れて絞る。キャンドゥだけは区分を絞らずにも検索し、株式会社キャンドゥがどの区分に登録しているか（第35類の小売りだけか、第28類なども持っているか）を見る。
- 類似群コードで絞る方法もある（ゲームのプログラムは 11C01、おもちゃ・ゲーム機は 24A01 などと AI は記憶しているが、確かめていない。J-PlatPat の「類似商品・役務審査基準」で確認する）。

### 2. USPTO Trademark Search（米国）

- URL: <https://tmsearch.uspto.gov/>
- 検索窓に `handmeup`・`hand me up`・`lendling`・`lendlings`・`wishnest`・`can do isles`・`cando`・`mottette` を1つずつ入れる。
- 左の絞り込みで **Status: Live**、**International class: 009・028・041** を選ぶ。死んだもの（Dead）も一度見て、最近放棄されたものがないか確かめる。
- 集約サイトで見つけた番号は、TSDR（<https://tsdr.uspto.gov/>）に出願番号を入れて今の状態を確かめる: 85133898（HAND ME UPS）、74115666（LEMMINGS）、76280378（CAN DO）、99810443（CANDO）。

### 3. TMview（欧州と多数の国の庁）

- URL: <https://www.tmdn.org/tmview/>
- 「Trade mark name」に上と同じ英字の語を入れる。「Offices」はすべて、「Nice class」は 9・28・41、「Trade mark status」は Filed・Registered を選ぶ。
- EUIPO だけ詳しく見るなら eSearch plus（<https://euipo.europa.eu/eSearch/>）でも同じ検索をする。

### 4. WIPO Global Brand Database（国際登録ほか）

- URL: <https://branddb.wipo.int/>
- 「Brand name」に英字の語を入れ、検索の方法を **Fuzzy**（あいまい）にする。「Nice class」で 9・28・41 に絞る。
- `LEMMINGS` と `CAN DO` は国際登録（マドリッド）で日本にも及んでいないかを見る。

### 5. ストア

- Steam・Google Play は、この調査では検索の部分一致が弱い。Steam のストアで `hand me`・`lend`・`wishnest` を、Google Play で `ハンドミーアップ`・`レンドリングス` を、ブラウザで一度検索しておく。
- 採る案が決まったら、公開の直前にもう一度ストアを検索する（その間に同名が出ることがある）。

### 6. 弁理士への相談（確実さが欲しいとき）
