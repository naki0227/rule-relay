- [ ] 範囲単発で一部だけ成功（禁止・塞がり）したときの返還: **1つでも成功すれば返還**（`BlockRules.single_shot_succeeded`）

- [ ] F で1つのブロックから回収する順番: **自分が貸したもの → レベルの禁止 → レベルの能力**、1回の F で1つ
- [ ] 範囲に一部だけ掛かったブロック: **中心が円内なら対象**。範囲回収は付与した層から上下3ブロック以内（仮）
- [ ] 範囲の禁止付与: **P0 では不可**（単体のみ）
- [ ] 「投げる」（2026-11-19 実装）: 能力トークンとして開始時からホットバー6にある。C で「投げる」を選べるのは、
  投げるが自分に効いているとき（ホットバーにあり、貸出中・禁止でない）だけ。投げるを渡すときは、その1回は投げる距離で
  届く（最後の投擲）。渡した直後から「触る」に戻る。F の回収は投げるの有無によらず触る距離（企画書 5.1）
  - ブロック・生き物に投げるを渡しても、持っているだけで効果はない（仮）。発動方式も持たない
- [ ] F で拾う（2026-11-19 実装）: 世界に落ちている器は、足もとから 1.8 以内で F を押すと通常インベントリへ入る。
  拾う前は禁止も自分に効かない。F の優先順位は 拾う → チェックポイントで保存 → 狙ったブロックから回収 → 範囲の回収（仮）
- [ ] 装備（2026-11-19 実装。企画書 7 の確定仕様＋仮の判断）:
  - 部位は頭・体・手・足で各1個。装備中だけ本人に効く。ホットバーに置いた装備品は効かない（付与の元にはできる）
  - 装備中は付与できない（EQUIPPED_CANNOT_LEND）。未装備ならホットバーから付与できる
  - **貸出中の装備は、回収するまで装備できない**（企画書で「実装前の確認事項」とされた AI 提案。仮に採用）
  - ジャンプブーツ＝高跳び（ジャンプの高さ 1.3 → 2.3、固定）。ジャンプ自体が使えない（貸出中・禁止）と跳べない
  - クライミンググローブ＝登る（壁へ向かって進む間、2.5m/秒で登る）。移動の能力・禁止は守る
  - ブロックに高跳びを渡すと、そのブロックの跳ぶ高さが 2.5 → 4.0（固定）。登る・投げるはブロックでは効果なし（仮）
  - 島の配置: 小島にジャンプブーツ、岩棚の東にクライミンググローブ（解法を増やす。唯一の通行証にはしない）
- [ ] 生き物（2026-11-19 実装。企画書 6 の確定仕様＋仮の判断）:
  - 「高いところへ行きたい」1匹。判断は `CreatureMind`（純粋な判断）: 探す範囲8マスで、いまより高く立てるマスへの道を
    幅優先で探す（SEEK）。進めなかった一歩は除いて探し直す（SEARCH）。道が無ければ待ち、1.5秒ごとに見回す（WAIT）。
    能力の変化・ブロックの移動／着地で判断し直す（4段階目）
  - 禁止は願いより優先（禁止を差し引いた「自分から始められる行動」だけで道を探す）
  - 単体付与だけ受け取る（範囲は不可）。発動方式は持たない。F で回収（自分が貸したもの → レベルの禁止 → レベルの能力）
  - 仮: 生き物の W/A/S/D は世界の方角に固定（ブロックと同じ）。島の1匹は W/A/S/D をレベル配置で持ち、ジャンプは持たない
  - 仮: 歩いて上がれる段 0.45、跳べる段はジャンプの高さ −0.2、自分から降りる高さは 2.5 まで
  - 仮: 見た目は丸い体・羽・芽の仮モデル。頭の上に「↑（向かう）／？（探す）／…（待つ）」を出す
  - 未: 生き物とプレイヤーは当たり判定しない（乗れない）。生き物の行動で高台へ行く解法は、まだ島に組み込んでいない
- [ ] 信号方式と音源（2026-11-19 実装。企画書 5.2 の確定仕様＋5.4 の仮の判断）:
  - 信号方式の能力は、音波が届いている間だけ繰り返しと同じ周期（1.4秒）で行動を試みる。途絶えると次の動作は休止し

  - 音源はブロックの一種で、周りへ音波を出し続ける（1.4秒ごとに輪と音）。能力を渡せば「移動する音源」になる
  - 仮: 届く距離は 6（3次元の距離）。遮るもの・音の種類・伝わる速さは未実装（企画書 5.4 の要検証）
  - 仮: 音源は止められない（止めるには遠ざける）。音を識別するブロックは未実装
  - 表示: 信号の能力を持つブロックの上に「♪ 受信中」／「休止中（音が届かない）」
