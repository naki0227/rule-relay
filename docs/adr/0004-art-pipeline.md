# ADR 0004: 3Dモデルは Blender のスクリプトで生成し、.blend と .glb を両方残す

- 状態: 採用（2026-11-18、試作段階）

## 決定

- 試作のモデルは `art/scripts/build_assets.py`（Blender の Python）で生成する。原本の `.blend` は `art/source/`、ゲーム用の `.glb` は `assets/models/` に書き出す。
- Blender は 4.5 LTS（4.5.16）に固定する。サポート期間が提出期限（2027-03-15）より長い。
- `art/` は `.gdignore` で Godot から除外する。Godot は `.blend` を直接読み込もうとし、Blender のパスが無い環境（CI）ではインポートが失敗するため。
- モデルは見た目だけで、当たり判定・ルール・テストはこれまでどおり箱で行う。見た目を差し替えても、解法の検証結果は変わらない。

## 理由

- スクリプトなら差分レビューができ、AI と人のどちらが直しても再現できる。形の調整（寸法・色・関節位置）がコードの1行で済む。
- 手足を関節ごとの別オブジェクトにして、コードで振る簡易アニメーションにした。骨格とアニメーションを作り込む前に、操作感を確かめる段階に合わせた。

## 欠点・見直し条件

- 有機的な造形（生き物、表情のあるキャラクター）はスクリプトでは限界がある。P1 で生き物を作るときは、Blender での手作業か Tripo を検討する。その場合は `.blend` を正本にし、スクリプトとの関係を `art/README.md` に書く。
- 骨格（Armature）とアニメーションが必要になったら、`traveler` を手作業の `.blend` に移す。
- 見た目の確認はソフトウェア描画（lavapipe の Forward+）で行った。Windows の実機・GPU では色や影が変わる可能性がある。
