# ADR 0022: 見た目の方向（空気・陰・手応え）と画質の設定

- 状態: 採用（2026-11-24、AI＝Claude Code が調べて決めた。色の好み・効果の量は本人の確認待ち）
- きっかけ: 本人の依頼「デザイン性の向上とか色々クオリティを高めるためにできることを実際のタイトルとかをみながら調査し、その上で作って欲しい」
- 調べたことと出典: `docs/quality/research.md`
- 画面: `docs/images/quality/`（`before-*.png` と `after-*.png`）

## 決定

1. **見た目の方向は「浮かぶ島の箱庭を、空気と陰で言い切る」**。特定の作品の見た目は写さず、調べた作品に共通する考え方だけを使う。
   - 空は上の青 `#4a90e2` から地平線の淡い水色 `#cde4f3` へ。島より下も白く飛ばさず淡い青にする。
   - 遠くほど空の色 `#cfe3f0` へ溶ける霧（濃さ 0.0045、広場は 0.0016）。霧は空には掛けない（グラデーションを残す）。
   - 高さ −3 m より下は高さの霧でかすませる（島の底・下の雲）。
   - 環境光は空の色に暖かい生成り `#fff0da` を 2 割混ぜ、影を青黒くしない。日の光は少し暖かく（`#ffebc9` 相当）、強さ 1.1。
   - 明るい所のにじみはソフトライトで控えめに。色の整えはコントラスト 1.05・彩度 1.12。
   - 島のまわりに遠い雲を 12 かたまり（全部で 1 つの MultiMesh）。ゆっくり回る。固定のシードで、どの画面でも同じ並び。
2. **地形は作るときに陰を焼き込む**（`TerrainMesher`）。面の前の層にとなりのマスがあれば、その角を 0.72〜1.0 に暗くする（入り組んだ角・壁の足もと）。丸めた縁の上向きの部分を最大 10% 明るくする。セルごとの明るさを ±3.5% 揺らし、草は広い範囲で黄緑へ最大 22% 寄せる。毎フレームの重さは無い。
3. **手応えは「音の合図」から作る**（`WorldJuice`）。島の場所つきの音（`sound_requested`）は参加者にもホストから届くので、みんなの画面に同じ効果が出る。通信の形は変えない。
   - 渡した: 受け取った物が「むにっ」とつぶれて戻る＋はちみつ色の輪＋光の粒。取り戻した: 小さく弾む＋生成りの輪。
   - ブロック・プレイヤーの着地と跳躍・ダッシュ: つぶれ・伸び＋足もとの土ぼこり。
   - クリア: 紙吹雪（`goal_reached`。協力中もどの画面にも届く）。
   - 動かすのは見た目のノードだけ（ブロックの `Model`、プレイヤーの `Visual`、生き物の `Body/Model`）。当たり判定・位置・台帳は変えない（`test_visual_quality`）。
   - 画面の揺れ・一瞬止める演出（ヒットストップ）は使わない（ゆるい雰囲気と、協力で他人の操作中に画面が揺れるのを避ける）。
   - 粒は同時に 16 組まで。効果の色に、禁止の赤・選択の夕日は使わない。
4. **区切りの瞬間**: クリアのカードは小さく縮んだ所から弾んで出て、上の 3 つの印が順に弾み、見出しが小さく跳ねる。文字は増やさない。ステージの出入りと「最初から」では、新しい島を生成りの幕から丸く開く（0.12 秒待って 0.6 秒で開く。入力は止めない）。
5. **草花・木の葉のそよぎ**は頂点シェーダー（`Foliage`）。モデルを初めて読むときに、揺らす部分のマテリアルを同じ色のシェーダーに置きかえる（メッシュは共有なので 1 回だけ）。幹・鉢は揺らさない。
6. **画質の設定（せってい → 画質）**: 低・中・高と、ミニチュア風のぼかし（あり・なし）。`user://settings.cfg` の `[display] quality / miniature_dof` に保存する。変えるとすぐ今の島に効く（`VisualQuality.apply_all`）。

   | 効果 | 低 | 中（はじめ） | 高 |
   |---|---|---|---|
   | 空・霧・色の整え・地形の陰・雲・つぶれて戻る・幕・クリアのカード | ○ | ○ | ○ |
   | 明るい所のにじみ（glow） | × | ○ | ○ |
   | 影の縁のぼかし（shadow_blur 1.6。低は 0.6） | × | ○ | ○ |
   | 草花のそよぎ | × | ○ | ○ |
   | 粒（輪・光の粒・土ぼこり・紙吹雪） | × | ○ | ○ |
   | 舞う花びらと光の粒 | 0 | 36 | 90 |
   | すき間の陰（SSAO） | × | × | ○ |
   | ミニチュア風のぼかし（遠くだけ。24 m から 18 m かけて） | 設定で選ぶ（はじめは なし） | 〃 | 〃 |

## 理由

- 空と霧は、どの画面にも効き、描く重さはほぼ無い。いちばん安く、いちばん大きく変わる（research.md の 3 章）。
- 頂点の陰は、SSAO と違って作るときに 1 回だけで済む。SSAO は高だけに下げても、壁の足もとの陰は残る。
- 手応えを音の合図から作ると、通信を足さずに協力の全員へ同じ効果が出せる。音の合図はもともと遊びの芯の操作にだけ出ている。
- 審査は普通の Windows PC（内蔵 GPU を含む）で遊ばれる。SSAO は重いので高だけにし、はじめは中にした。

## 変えないもの・ほかの作業との境目

- **WorldEnvironment の既定値を変えた**（性能の作業 `claude/perf-pass` への知らせ）: SSAO は「常に入」から「画質の高だけ」に、にじみは加算・しきい値 1.2 からソフトライト・しきい値 1.0・強さ 0.95 に、霧は濃さ 0.004 から 0.0045 と高さの霧に、環境光の強さ 0.5 から 0.55 に、トーンマップの白 6.0 を足した。日の光の向き・影の距離（60 m）は変えていない。
- プロジェクト設定（レンダラー・影のアトラス・柔らかい影の質・SSAO の質）は変えていない。性能の作業はそちらで調整してよい。画質の設定は、効果の入り切りだけを受け持つ。
- 広場の霧の濃さ（`OverworldDressing._soften_fog`）は 0.0012 から 0.0016 にした（空の色を島と同じにしたため、遠くの見え方をそろえた）。
- ルールの読みやすさ: 禁止の印・メダル・巣の光の柱・照準・ヒントの表示は変えていない。霧で遠くの巣の光が消えないよう、霧は控えめにした。ぼかしは既定で切る。

## 採らなかった案

- 輪郭線・トゥーン調の陰: いまのやわらかい陰と合わず、全モデルの見直しが要る。輪郭線は画面ごとの処理で重さも出る。
- SDFGI・ボリュームの霧: 内蔵 GPU で重い。
- 画面の揺れ・ヒットストップ: ゆるい雰囲気に合わず、協力で他人の操作のたびに揺れると疲れる。
- ステージの出入りで、出る前に幕を閉じる: 島の切りかえは進行役（PartyDirector）が決めるので、閉じる時間を足すと進行の時間が変わる。開くほうだけにした。

## 見直す条件

- Windows 実機で、中の画質が内蔵 GPU で 60fps を割るとき（にじみ・花びらを低へ寄せる）。
- 本人が色・効果の量を変えたいとき（`WorldLook` と `VisualQuality.TABLE` の定数だけで変えられる）。
- 世界観が決まって空の時間帯（夕方・夜）が要るとき。
