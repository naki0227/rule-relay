# ADR 0019: 生き物は行ける所まで向かい、足りないものを吹き出しのメダルで見せる（ビヘイビアツリー）

- 状態: 採用（2026-11-21）
- きっかけ（本人の言葉）:
  - 「動物さ、完全に道見つかるまで動かへんやんか。向かってくれればいいのになって。例えば、ジャンプと W ないと
    登れへんけど、W で壁の前まで行って、ジャンプもあればな、みたいな。」
  - 「そのビヘイビアツリーみたいな感じで動けるんやったら動かしてほしいな、普通に。」
  - 「足りひんやつとかをコメントで言うんじゃなくて、吹き出しの中に欲しいこういうメダルのやつ、アイコンみたいな。」
- 前提: ADR 0016 の 4・5（ふもとまで歩く・頭の上の印）。この ADR がそれを置き換える。

## 決定

1. **ふるまいを小さなビヘイビアツリーで選ぶ**（`src/rules/behavior_tree.gd`・`src/rules/creature_brain.gd`）。
   上から順に試し、最初に当てはまった葉をする:
   1. 願いがかなった（巣の箱の中）: 一度だけ喜ぶ（`happy`）。そのあとは巣の中で見回す・巣の中のマスだけを少し歩く・
      近くのプレイヤーを見る。巣からは出ない（前は巣より高い所が見えると巣を出ることがあった）
   2. 完全な道がある: たどる（`CreatureMind.plan`。いままでと同じ道・同じ探す範囲 8 マス・1.2 秒で別の道）
   3. 行き先はあるが道が足りない: いまの能力で行ける範囲で、行き先にいちばん近いマスまで歩く
      （`CreatureMind.best_effort`。ADR 0016 の「ふもとまで 4 歩」を一般にしたもの。別の仕組みは作らない）。
      止まったら、足りないもの（`CreatureMind.missing`）を吹き出しに出して待つ。待つ間は行き先（壁）や近くの
      プレイヤーを見る・役に立たないジャンプを持っていればその場で小さく跳ねる・見回す
   4. 移動はあるが行き先が無い（巣が無く、高い地形も見えない）: 止まった所から 2 マス以内を少し歩く
   5. 移動が無い: その場で近くのプレイヤーのほうを向き、移動のメダルを出す
   - 乱数は生き物の ID を種にする（`CreatureBrain.reset`。チェックポイントから戻すと最初から）。同じ入力なら同じふるまい
   - 見回す・跳ねる・喜ぶは**見た目だけ**（骨格のアニメーション。位置も、W/A/S/D の基準の向き `facing` も変えない。
     投げる生き物の投げる向きも変わらない）。体だけを見る先へ向ける
2. **行き先**: 巣（クリア条件「巣へ運ぶ」の箱）。巣が無ければ、いちばん近い高い地形（ADR 0016 と同じく地形だけから選ぶ）。
   「近い」は行き先の四角までの水平の距離で、同じなら高いほう、それも同じなら近い（先に見つかった）ほう。
3. **近づくとき・散歩するときの守り**:
   - **もう壁の前にいるなら、壁ぞいに横へ歩いてまで近づかない**（行き先に近づく向きのとなりが、いまの能力では上がれない
     高さか穴なら「壁の前」。`CreatureMind.at_wall`）。本人の例は「W で壁の前まで行って」で、壁ぞいに滑ることではない。
     2-5「鳴りつづける鐘」の子どもは最初から段の壁の前にいる。横へ歩かせると信号の石の最初の位置が探す 8 マスに入り、
     鐘を鳴らす前に石で段へ上がって発射台の上へ行ってしまった（`test_gate_one_ring_is_not_enough_for_the_stone`・
     協力の通しプレイで見つけた。ステージの置き方は変えずにこの規則で直した）
   - 跳び降りない（自分から降りる段は 0.45 まで）。前より低い所へ行って戻れなくならない
   - 重さの板・ワープの石・スイッチの扉・レバー・時の鐘・鐘のマスは通らない（`WorldQueries.creature_avoid`）。
     勝手に乗って謎を解いたり崩したりしない。完全な道（高い所への道）は、いままでどおりこれらも通る
   - **段の縁にいるときは、同じ高さの縁のマスだけを通る**（となりに歩いて降りられないほど低いマスがあるマス）。
     1-3「持ち上げ台の段々」の「動物が段の縁にいる間は、下から F で取り戻せる」を守る。縁から内側へは歩かない
   - 止まる所は、ブロックや置物の上ではない「ふつうの地形」だけ（通るのはよい）
   - 散歩はさらに、いまと同じ高さのふつうの地形のマスだけを通る
4. **足りないもの**（止まった所から、足すと完全な道ができるか、行き先へ近づけるか）:
   - 移動が無い → 移動のメダル（移動だけでは進めず、ジャンプもあれば進めるならジャンプも並べる）
   - 移動はある → このステージにある能力のうち、ジャンプ → 高跳び（ジャンプも無ければ両方）→ 登る の順で、
     足すと進めるもの。ステージに無い能力は言わない
   - どの能力でも進めない（段が高すぎる・谷）→ 「道が要る」
5. **吹き出し**（`CreatureWishView`）: 足りないものは文字や知らせで言わず、頭の上の吹き出しだけで見せる。
   - 中身: ホットバー・器と同じメダルの絵（多くて 3 つ並べる）／道が要るなら小さな階段の絵／かなったら緑の ♪
     （2.5 秒で消え始める）。歩いている間・何も足りないものが無いときは出さない
   - カメラのほうを向き、ゆっくり上下する。カメラから 10 m までははっきり、18 m で消える
   - 「ここから上がれない…（道が要る）」の知らせ、「移動？」「↑×」などの印はやめた。願いの一文
     （「高いところの巣へ行きたい」）は、近くに来たか狙ったときだけ、いままでどおり上に小さく出す
   - 参加者の画面: 吹き出しの鍵（`need:4` のように足りない能力の種類を並べたもの・`path`・`happy`）と、
     見た目の動き（名前・回数・体の向き）を `WorldFrame` で配る
6. **置かれた直後・チェックポイントから戻した直後は 0.6 秒落ち着いてから動く**（戻した位置がすぐ崩れない）。
7. **落ちてくるブロックをよける**: 壁のふもとで待っていると、プレイヤーがそこへ足場を落とすことが多い（1-4 の削った
   階段）。ブロックは生き物と衝突しないので、自分のマスの上にブロックが来たら、同じ高さのとなりのマスへ急いでよける。
8. **最初から移動を持っている生き物も**、同じツリーで動く（前は置かれた場所で待っていた）。本人の「動けるんやったら
   動かしてほしい、普通に」に合わせた。全部のステージのゲート・通しプレイ・探りのテストで確かめた（下の「確かめたこと」）。
9. 骨格のアニメーションに `look`（見回す）と `hop`（その場で跳ねる）を足した（`art/scripts/build_cast.py`、生き物と子ども）。

## 変えないもの

- 完全な道があるときは、いままでとまったく同じ（同じ道・同じ段階・同じ探す範囲）。
- 2-5「鳴りつづける鐘」: 巣の無い生き物の行き先は地形だけから選ぶ。近づくときは鐘・扉（橋）のマスを通らず、
  止まる所はふつうの地形だけ（発射台や石などのブロックの上では止まらない）。近づく道は跳び降りもしない。
- 探す範囲 8 マス・1.2 秒で別の道・1.5 秒ごとに見回す、は変えない。

## 採らなかった案

- 近づく道を ADR 0016 と同じ「同じ高さ・4 歩」に限る: 本人の例（W で壁の前まで行く）に届かないことが多い。
  代わりに、跳び降りない・縁にいるなら縁だけ・仕掛けを通らない、で守る。
- 足りないものを文字（「ジャンプもあればなあ」）や知らせで言う: 本人が「コメントで言うんじゃなくて」と止めた。
- 見回す・跳ねるで本当に向きを変える・跳ぶ: W/A/S/D の基準や投げる向き・重さの板が変わり、謎に影響する。見た目だけにした。
- ふるまいを状態機械で書く: 本人がビヘイビアツリーを指定した。葉の順番がそのまま優先順位になり、テストで葉の選び方を確かめやすい。
