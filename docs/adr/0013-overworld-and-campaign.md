# ADR 0013: 広場をオープンワールドの「オーバーワールド」にし、キャンペーンをワールドに分ける

- 状態: 採用（2026-11-21。土台の段階。新しいステージは次の段階で、ワールドごとに並行で作る）
- 本人の決定（2026-11-21）:
  - 雰囲気は「ゆるふわで温かみのある3Dブロックの箱庭」。明るい昼・丸くてかわいい生き物・やさしく暴力のない世界。
    参考にした有名な作品からは何も写さない（キャラクター・UI・名前・物語の入口・「人がいなくなった世界」）。物語は脇役。
  - 一列の入口の広場（ハブ）を、歩き回れるオープンワールドの広場（オーバーワールド）にする。
  - 広場にワープの門（ポータル）を置き、入るとステージ（ダンジョン）へ行く。
  - ステージをクリアするほど広場が広がり発展する（新しい地方が開く・橋が架かる・建物が増える）。
  - 能力は広場でも使える（貸す・ブロック・ジャンプ・ダッシュなど）。小さな仕掛けと秘密をたくさん置く。
  - 各ステージには願いを持つ動物がいて、助けると広場に住む（「閉じ込められた動物を救う」話にはしない）。
  - 規模は「マリオのように」: ステージが多く、数ステージごとに新しい能力、各ステージに新しい仕掛けか新しい組み合わせ、
    各ワールドの真ん中と最後は難しく、進行に要らない寄り道のワールドはとても複雑で難しい。
  - 動くもの（生き物・キャラクター）は部品ごとに作り、骨格（Rig）とアニメーションで動かす（同日の追加の指示）。
- 守る原則（変えない）: 「ルールは厳格に。解法は自由に。」／自由な遊びを止めるシステムのルールは足さない（地形で作る）／
  クリアは島の条件＋生きている全員がゴールに集まる／受け入れた技は残す（縁ちょうどの幅 4・ブロックの上昇＋自分のジャンプ・
  どの地面のセルも持ち上げ台にできる）／ダッシュは W/A/D が要り、床に着くまで 1 回、後ろへは無し。
- 関連: ADR 0008（進行と報酬）、0009（ステージの定義）、0010（進行役）、0011（ステージの並べ方と開けた島）

## 決定

1. **キャンペーンの設計はコードのデータ（`CampaignPlan`）に置く。**
   - 本編 7 ワールド × 6 ステージ（42）＋寄り道 3 ワールド × 5 ステージ（15）。全体の表は `docs/campaign-plan.md`。
   - 枠（`CampaignPlan.Slot`）は、まだ作っていないステージの分もある。作る人は、その `stage_id` の `StageDef` を
     `StageCatalog.all_stages()` に足すだけで、広場のその地方の決まった場所にポータルが現れ、開き方・住む生き物・
     建物も枠のとおりになる（並行で作るための入口）。
   - 今ある 12 ステージは、はじめの方のワールドに割り当てた（草原 4・鐘の谷 3・浮島 1・森 1・札の庭 2・峰 1）。
2. **広場の id はハブと同じ（`StageCatalog.HUB_ID`）にし、中身を `Overworld.build(OverworldState)` で作る。**
   - `OverworldState` は「クリアしたステージ・ポータルを全部開けるか・地方を全部つなぐか・能力を全部持たせるか」だけ。
     地形・ポータル・住む生き物・建物・開始時の能力は、これだけから決まる純粋な関数なので、単体テストで確かめられる。
   - 協力中はホストの進行で決める（これまでの入口の開き方と同じ）。ホストは `_enter` の RPC で状態を配り、
     参加者はそれで同じ広場を組み立てる。ホスト移譲では、試遊の設定だけを前のホストから引き継ぎ、クリアの記録は
     新しいホストのものを使う。
3. **地方は地形だけで開く。** 閉じた地方へは、谷（底なし）か岩でつながっていない。クリアで、橋が架かる（鐘の谷・浮島・
   札の庭）・岩がどく（けものの森）・階段がせり上がる（霧の峰・空の頂）。通せんぼのルールは足さない。
   - 地方を開くステージは、前のワールドの最後のステージ。まだ作っていなければ、前のワールドで最後に作ってあるステージで
     代わりに開く（`CampaignPlan.required_stage`）。
   - 受け入れた技（地面のセルを持ち上げ台にする・ブーツの高跳び）で、閉じた地方へ先に渡れることがある。止めない。
4. **ポータル**（`OverworldPortal`、モデル `portal_arch`）: 石と葉のアーチの中で空色の渦が回る。上に番号・名前・目安時間・
   F の文字。閉じた門は渦を灰色にして止め「まだ開いていない」。クリアした門は、てっぺんに金色の花の印。
   入る操作はこれまでの入口と同じ（`EntranceSpec` の箱の中で F）。導入のポータルは出現地点の真正面（`docs/onboarding.md`）。
5. **開き方の設定**（`PartyDirector`）: `all_stages_open`（ポータル。試遊の版は true のまま）に加えて、`all_regions_open`
   （地方。試遊の版は true）と `all_abilities_unlocked`（デバッグ。false）。コマンドラインの `--campaign` で製品版の開き方、
   `--open-all` で全部開ける（`docs/how-to-test.md`）。
6. **広場の能力**: W/A/S/D・ジャンプと、クリアで開いた能力（`CampaignPlan.unlocked_actions`）。ブーツ・グローブは
   装備した状態で渡す（`StageDef.start_equipment`）。ステージの開始時の能力はステージの定義のまま。
   報酬表（ADR 0008）の「恒久的な強化でパズルを崩さない」を守るため、開いた能力が効くのは広場だけ。
7. **住む生き物と建物は見た目だけ**（当たり判定・台帳・ルールなし）。クリアしたステージの枠の生き物が、ポータルのそばの
   家のまわりを少し歩き回る（`OverworldResident`）。建物は 6 種のモデルを枠ごとに選ぶ（家・風車・噴水・畑・見晴らし台・屋台）。
   どの画面でも同じ乱数で動くので、協力中も同期しない。
8. **草原の小さな仕掛け**（どれも今ある仕組みだけ）:
   - 高台: 窪みのブロックにジャンプを貸して乗ると、上に見晴らしの発見（`test_the_ledge_puzzle_is_solved_by_walking`）。
   - 鐘の扉: 鐘を鳴らすと、扉のブロック（信号の W）が北のくぼみへすべり、寄り道「からくり工房」の門の庭に入れる。
     扉に自分の W を渡しても開く（解き方は自由）。
   - 札の門: 門のブロックに W・S・A の禁止の札。札を回収すると自分が動けなくなるので、手放してから A を渡すと、門がくぼみへ
     どいて寄り道「ひみつの温室」の門の庭に入れる。壁（高さ 3）は、地面のセルを持ち上げ台にする技でも越えられる。
   - 発見は「入ると知らせが出る」だけ（`StageWorld.found_secrets`）。記録や報酬にはしない（保存の仕組みを増やさない）。
9. **動くものは骨格とアニメーションで動かす**（2026-11-21 本人の指示）。
   - Blender のスクリプト（`art/scripts/rig.py`）で、部品ごとのメッシュを 1 本の骨に重み 1.0 で結び、アクションを NLA に積んで
     glTF に書き出す。Godot では `Skeleton3D` と `AnimationPlayer` になり、`RigAnimator` が状態で切り替える。
   - 骨格付き: プレイヤー（idle / walk / jump / happy）、願いを持つ生き物と子ども、広場の生き物 2 種（耳の長い生き物・
     もこもこの生き物）（idle / walk / happy）。風車の羽根（spin）とポータルの渦（swirl）はオブジェクトのアニメーション。
   - 当たり判定は箱・カプセルのまま。手足をコードで振る処理（`PlayerAvatar._animate_limbs` の関節の回転、生き物の上下）はやめた。

## 採らなかった案

- **地方を「クリアするまで入れない見えない壁」で閉じる**: 本人の原則（システムで止めない）に反する。地形で閉じる。
- **ワールドごとに別のシーン（別の広場）にする**: 「歩いて回るひとつの箱庭が育つ」体験にならない。ロードは短い（ADR 0011）
  ので分ける理由も弱い。
- **開いた能力をステージにも持ち込む**: ステージの初期能力の制約が崩れる（ADR 0008 の報酬表と同じ理由）。
- **発見を進行に保存して報酬にする**: 協力中に誰の発見か・二重に渡さないかの仕組みが要る。今は知らせだけにし、要るなら
  報酬イベント（ADR 0008）の形で足す。
- **手足をコードで振り続ける**: 本人の指示（部品ごとに作り Rig で動かす）。表情の幅も狭い。
- **建物をステージごとに 1 つずつ作る**: 今の段階では 6 種を使い回す。世界観が決まったら増やす。

## まだやっていないこと・仮の点

- 新しいステージ（45 枠）と、新しい仕掛け・能力のコード（`CampaignPlan.NEEDS_CODE`）。
  風・氷・水と流れ、能力の重い・浮く・泳ぐは 2026-11-21 に作った（ADR 0015）。
- 寄り道のワールドのポータルの置き方（今は庭の中に閉じた門が 1 つ。ステージを作るときに並べ方を決める）。
- 今あるステージのうち、生き物がいないステージにも「願いを持つ動物」を置くこと（物語の枠だけ先に決めた）。
- 目安時間・ワールドの順番・地方の形はすべて仮。本人の試遊で直す。
- 発見の知らせは自分の画面だけ。建物の当たり判定は無い（歩いて通り抜ける）。
- 画面: `docs/images/overworld/`（lavapipe での描画。実機では色が少し違うことがある）。
