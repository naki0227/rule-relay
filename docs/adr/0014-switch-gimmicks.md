# ADR 0014: スイッチの仕掛け（重さの板・スイッチの扉・レバー・時の鐘・ワープの石）

- 状態: 採用（2026-11-21。仕掛けの部品とテストまで。キャンペーンのステージでの置き方は、ステージを作るときに決める）
- 背景: キャンペーンの計画（ADR 0013・`docs/campaign-plan.md`）の「要実装」の仕掛けのうち、時の鐘（2-5）・重さの板（4-4）・
  ワープの石（6-1）・スイッチと扉（O1）。風・氷・水・浮く・重いは別の作業（`claude/gimmicks-b`）で並行して作る。
- 守る原則（本人。変えない）: 「ルールは厳格に。解法は自由に。」／自由な遊びを止めるシステムのルールは足さない（地形で作る）／
  1〜4 人の協力でホスト権威。状態は配信し、チェックポイントと全員リセットで記録・復元する／ゆるふわで温かい見た目。
- 関連: ADR 0003（ブロックの運動）、0006（通信）、0009（ステージの定義）、0013（キャンペーン）

## 決定

1. **定義は `StageDef.mechanisms`（`MechanismSpecs`）に置く。** 中身は 5 種の配列（`plates` / `doors` / `levers` /
   `timed_bells` / `warps`）。key はステージの他の key（ブロック・生き物・鐘）と重ならない（`StageDef.problems` が確かめる）。
   「床のセル」は、その上面に立つセル（地面の上面が y = 0 なら y = 0）。

   | 種類 | 定義（フィールド） |
   |---|---|
   | 重さの板 `PlateSpec` | `key`・`cell`（床のセル）・`size`（x・z の広さ、既定 1×1）・`required_weight`（既定 1）・`signal_radius`（既定 0） |
   | スイッチの扉 `DoorSpec` | `key`・`cell`（最小の角）・`size`（既定 幅 1・高さ 2・奥 1）・`sources`（源の key）・`mode`（`HELD` / `TOGGLE`）・`require_all`・`inverted` |
   | レバー `LeverSpec` | `key`・`position`・`start_on`・`signal_radius` |
   | 時の鐘 `TimedBellSpec` | `key`・`position`・`ring_time`（秒、既定 3） |
   | ワープの石 `WarpSpec` | `key`・`cell`（床のセル）・`partner`（行き先の石。空なら出口だけ） |

2. **組み立てと判断は `MechanismSet`（`src/game/gimmicks/`）。** StageWorld が作り、世界の子 `Mechanisms` に置く。
   GameWorld には変数を足さず `MechanismSet.of(world)` で探す（並行の作業と共有ファイルでぶつからないように、共有ファイルの
   変更は数行の呼び出しだけ）。ホスト（1 人用も）だけが判断し、参加者は届いた状態を見せる。台帳には触らない。
3. **重さの板**: 足もとが板の上（面から ±0.35）にあるプレイヤー・ブロック・生き物を 1 ずつ数え、`required_weight` 以上で押される。
   - 当たり判定は持たない（床に貼りついた薄い板。ブロックの動き・生き物の道を変えない）。跳んでいる途中は乗っていない。
   - 押されている間、つながった扉の入力になる。`signal_radius > 0` なら、鐘と同じ音波も出す（押し続ける鐘。信号の方式で
     渡したブロックが動く）。`GameWorld.is_receiving_signal` が鐘の後に板とレバーを見る。
   - 「重い」（`HEAVY`）の重さは別の作業で足す（`MechanismSet._bodies` の重さを 1 から変える）。
4. **スイッチの扉**: 地形と同じ層の箱（`AnimatableBody3D`）。開くと高さ分だけ床へ沈む（0.6 秒）。
   - `HELD`: 入力がある間だけ開く。`TOGGLE`: 入力が入り始めるたびに開く ↔ 閉じる（板・鐘を持続のスイッチにする）。
     `inverted` は逆（入力が無いときに開いている）。`require_all` は全部の源（2 枚の板を 2 人で、など）。
   - 源は板・レバー・時の鐘・ステージの鐘（`StageDef.bells`）。レバーはそれ自体が持続なので、ふつうは `HELD` の扉とつなぐ。
   - **挟まない**: 閉じる向きに動く前に、閉じた箱の中（体の幅 0.3 を足す）に誰か（何か）の体の真ん中があれば、出るまで
     その高さで待つ。開く向きは待たない。戸口に立って扉を開けておくのも自由な解法として残す（ルールでは止めない）。
   - 端に着いたら生き物に道を探し直させる（扉は地形として道を変える）。
5. **レバー**: 近く（水平 1.4 以内）で F を押すと入る ↔ 切れる（持続）。当たり判定は持たない。足もとに拾える物があれば拾う方が先。
   参加者の F はこれまでどおりホストへの依頼になり、ホストがその人のアバターの位置で判断する。
6. **時の鐘**: 鳴る秒数を決められる鐘（`TimedBell` は `Bell` の子。`Bell.ring_time` を足した）。世界の鐘（`world.bells`）に
   入るので、F・投げた玉・信号の方式・扉の源・ACTIVATE のクリア条件・記録・配信がふつうの鐘と同じ道を通る。
   残り時間は足もとの輪が縮んで見せ、残り 1 秒で夕日色になる。脇の砂時計が鳴らすたびにひっくり返る。
   既存の信号の方式と組むと、時間の中で動かすパズルになる（鳴っている間だけ跳ぶブロック・開いている扉）。
7. **ワープの石**: 乗ったもの（プレイヤー・ブロック・生き物）を `partner` の石の中心へ移す。端の扱い:
   - **行き先がふさがっている**: 行き先の石の上に誰か（何か）が乗っていれば移さず、降りるまで待つ。両方の石に同時に
     乗っていれば、どちらも移らない（どちらかが降りれば動く）。
   - **行き来しない**: 着いたものは、その石から一度降りるまでその石では移らない。移った直後 0.6 秒はワープの判断から外す
     （参加者の位置の報告が遅れて届いても、行って戻らない）。
   - **ブロック**: 止まってマスに収まってから移る（動いている途中・跳んでいる途中は移らない）。付いている能力・禁止は
     そのまま一緒に移る（台帳は変わらない）。上に乗っている人は一緒には移らない（自分で石に乗る）。
   - **片道**: `partner` が空の石は出口だけ。互いを `partner` にすれば往復。
   - 移すとブロックより先に動く（`process_physics_priority = -1`）。同じフレームでブロックが自分の動きを物理へ送った後に
     瞬間移動させると、送った動きで元の場所へ戻されるため（`AnimatableBody3D` の同期移動）。
8. **通信と記録**
   - 配信（`WorldFrame` の `mechanisms`）: 板の押下・レバー・扉の開き具合・石の光った回数と、仲間をワープさせた切符
     （プレイヤー ID → [番号, 位置]。1.5 秒だけ配る）。参加者は自分宛ての新しい切符で自分のアバターを動かす（アバターは
     各自が動かすため）。扉は届いた開き具合へなめらかに近づける（大きくずれたらすぐ合わせる）。
   - 記録（`WorldSnapshot` の `mechanisms`）: 板・レバー・扉（開き具合・切り替えの向き・前の入力）・ワープの着いた印と
     外している時間。時の鐘の残り時間は鐘の記録に入る。チェックポイントと全員リセットで戻る（参加者には配信で届く）。
9. **見た目**（`art/scripts/build_switches.py`。部品ごとに作って骨に結び、アクションで動かす）
   - `pressure_plate`（石の縁と木の天板。天板が沈む `press`）・`switch_door`（木の板と石の帯と空色の印。床へ沈む `open`）・
     `switch_lever`（石の台と木の柄。倒れる `flip`）・`warp_stone`（平たい石と浮かぶ結晶。ゆれる `hover`・光って跳ねる `warp`）・
     `bell_timer`（時の鐘の脇の砂時計。返る `flip`）。
   - 板・扉・レバーは状態の度合いで再生位置を合わせる（`RigPose.hold`）。参加者の画面でも届いた状態から同じ姿になる。
   - 音は既存の SoundBank の音だけ: 板は `block_step`（押すと高く、離すと低く）、扉は動き出しに `block_step`（低く）と
     `block_land`、レバーは `block_step`、ワープは `dash`、時の鐘は `bell`。

## 採らなかった案

- **板・石に当たり判定を持たせる**: ブロックの 1 マスの動きと生き物の道探しが、薄い段差でずれる。床に貼りつく見た目だけにした。
- **扉が閉じるときに中のものを押し出す・閉じるのを止めない**: 挟まれて詰む・押し出されて落ちる。待つ方が「ルールで止めない」と
  両立する（戸口に立てば開けておける、という自由な解き方も残る）。
- **扉を `TerrainGrid` のセルにする**: 地形のセルは能力を渡すと動くブロックになる（ADR 0013 の受け入れた技）。扉に能力が
  渡せると「開かない扉は地形」の約束と混ざるので、扉は付与先にならない別の体にした。
- **ワープで乗っている人も一緒に移す**: 何が一緒に移るかの規則が増える。乗っている物ではなく「石に足が着いているもの」だけにした。
- **参加者のワープを新しい RPC にする**: 進行役（PartyDirector）や NetWorld を変えずに済むよう、毎フレームの配信に切符を載せた。
  配信は順序付きの非信頼なので、切符は 1.5 秒配り続け、参加者は番号で一度だけ従う。
- **レバーの切り替えでも `TOGGLE` の扉が閉じる**: 「入り始め」で切り替える、の一つの規則にした。持続のレバーには `HELD` の扉を使う。

## まだやっていないこと・仮の点

- キャンペーンのステージ（2-5・4-4・6-1・O1）での置き方。数値（扉の 0.6 秒・板の ±0.35・時の鐘の既定 3 秒）はすべて仮。
- 「重い」の重さ（別の作業）。扉が横へ開く形・持ち上がる台（今は床へ沈む扉だけ。動く台は板の音波と信号の方式で作る）。
- 扉・板・石の照準の表示（狙っても何も出ない）と、HUD での案内。
