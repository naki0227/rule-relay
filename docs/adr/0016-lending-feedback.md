# ADR 0016: 渡すときの見せ方（範囲の表示・照準の補助・生き物の反応）

- 状態: 採用（2026-11-21）。4（ふもとまで歩く・↑× と知らせ）と 5 の「足りないもの」の印は、同じ日に ADR 0019（行ける所まで向かう・吹き出しのメダル・ビヘイビアツリー）で置き換えた。
  2026-11-23 本人の判断で、見上げたときにカメラの支点を上げた（ADR 0021 の 2）。2 の照準の光線と 3 の照準の補助は、上げた支点でも照準の円と合う（`test_camera_pivot`）。
  1-4 の巣の光の柱は、近く〜中くらいのきょりで画面の真ん中と上の帯を薄くした（ADR 0021 の「ステージ側の残り」）
- きっかけ: 本人が「押し石の小道」（1-4）を初めて遊んだときの不満（要約）: 能力を渡しても生き物が動かない、
  ブロックと動物を狙うのが難しい、範囲付与の表示がごちゃごちゃしている。
  その後の本人の訂正: 地面に範囲で渡すこと自体はよい。いらないのは UI のごちゃごちゃ。

## 決定

1. **範囲付与の対象は変えない**（地形のセルも、いままでどおり範囲で受け取る。ADR 0003・PR #21）。変えたのは表示だけ。
   - プレビュー: 円の線1本と、選ばれる層の上面に敷く薄い円板（`RangePreview`）。半透明の筒・二重の縁・ブロックごとの
     角マーカー・「範囲に渡す n こ」の札はやめた。
   - 付与中の範囲: 赤い円の線と、円の中心のアイコン1つ（`RangePreview.sync_lent`）。範囲で受け取ったブロックには、
     ブロックごとのアイコン・「範囲・繰り返し」の文字・赤い枠を出さない（地面に渡すと数十のセルに重なって読めなかった）。
     単体で受け取ったもの・置かれていた禁止は、いままでどおりブロックの上に出す。
   - 撮った画面: `docs/images/ux/range-ground-*-before.png` / `-after.png`（`tools/capture_range_ux.gd`）。
2. **照準の光線を、画面の照準に合わせる**。カメラは肩越し（`h_offset` 0.6）なのに、光線をカメラの正面から投げていて、
   照準より 0.6 左を狙っていた。`project_ray_origin` / `project_ray_normal` で画面の中央から投げる。
3. **照準の補助（`AimAssist`）**: 光線が付与先に当たらない（何にも当たらない・地形に当たる）ときだけ、画面で照準から
   画面の高さの 6% 以内にある、いちばん近い付与先（ブロック・生き物・鐘・発射台・仲間）を選ぶ。届く距離（触る／投げる）と、
   カメラから見えていること（地形やほかのブロックに隠れていない）が条件。壁越し・届かない所へは渡せないまま。
   地形のセルと、地形から動くブロックにしたセルは候補にしない（地面を狙ったつもりで吸い寄せない）。
   照準の下に、狙っている相手の名前（「子どもの生き物」「ブロック」など。地形のセルには出さない）を出す。
4. **生き物の反応**: 移動をプレイヤーからもらったのに高い所への道が無いとき、同じ高さのマスだけを通って 4 歩以内で
   ふもとに着けるなら、いちばん近い高い場所のふもとまで歩いて止まる（`CreatureMind.approach_path`。段階は WAIT のまま）。
   止まったら頭の上に赤い「↑×」と、一度だけ「（名前）: ここから上がれない…（道が要る）」を出す。移動が無いときは「移動？」と、
   狙ったときの案内「移動の能力を渡すと歩き出す」（慣れるまで）。
5. **生き物が何を求めているか**（2026-11-21 本人「どうぶつがなにをもとめてるのかがわかりにくい」）:
   - 行き先: クリア条件「巣へ運ぶ」（`ClearCondition.carry_area`）の箱の床に薄い輪と光の柱（`WishMarker`）。
     願いがかなったら消える。生き物の近くにいるか狙っているときだけ、巣が画面の外なら縁に矢印（`WishPointer`）。
   - 足りないもの: 頭の上の印は1つだけ（`CreatureWishView`）。移動が無い → 移動のアイコン＋？、ジャンプがあれば
     上がれる → ジャンプのアイコン＋？、道が要る → 赤い ↑×、巣に着いた → 緑の ♪。
   - 願いの一文: 近く（4 m）にいるか狙っている生き物1匹だけ、印の上に出す。`StageDef.CreatureSpec.wish_text`、
     空なら巣があれば「高いところの巣へ行きたい」、無ければ「高いところへ行きたい」。
   - 参加者の画面: 行き先と一文はステージの定義から同じに作り、印の鍵はホストが `WorldFrame` で配る。
   - 1-4 の画面: `docs/images/ux/wish-push-path.png`。

## 理由と、変えないもの

- 歩くのは同じ高さだけ・ふもとまで 4 歩以内だけなので、前より高い所・遠い所へは行かない（関所は変わらない）。
  遠い崖へ向かって歩き出すと、段の縁で待つ生き物（1-3 の動物など）から下のプレイヤーが能力を取り戻せなくなるので、歩かない。
- 最初から移動を持っている生き物は、置かれた場所で待つ（ステージの置き方を変えない）。
- 近づく先の「高い場所」は地形だけから選ぶ。ブロックや鐘の上も選ぶと、2-x「鳴りつづける鐘」で子どもの生き物が
  鐘のほうへ歩き、発射台の上に乗って橋を渡らなくなった（`test_world2_timed_bells`）。
- 光線を照準に合わせたことで、採石場のゴールの窪みから跳んで、崖の上の仲間に照準が合う点が 1 つ増えた
  （`test_goal_probes` の測定値を更新。跳んで狙うのは G2 で受け入れた技）。

## 採らなかった案

- 範囲付与をブロックだけに戻す: いったん指示されたが、本人が「地面に範囲渡していい」と訂正した。
- 照準の補助の半径を大きくする: 地面のセルを狙いたいときに、近くの生き物やブロックへ吸い寄せられる。
  画面の高さの 6% にとどめ、近くに何も無ければ地形のセルをそのまま狙える。光線が付与先に直接当たったときは補助しない。
