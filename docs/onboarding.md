# はじめての人が覚えること（オンボーディング）

2026-11-20 時点（2026-11-21 に広場をオーバーワールドにした変更を追記）。外部の人に 15 分遊んでもらう前に、タイトル → 広場（ハブ）→ 導入「跳ぶ力を貸す」→ クリアまでの最初の 5 分を見直した記録と、試遊を見守るときのチェックリスト。

## 2026-11-21 広場がオーバーワールドになって変わったこと

- 一列の入口の広場が、歩き回れる箱庭（`docs/adr/0013-overworld-and-campaign.md`）になった。**出現地点の真正面に導入のポータル**（約 6 m 先）、看板の「はじめはここから」はそのまま。最初の数分の流れ（歩く → 見回す → ポータルで F → 導入）は変えていない（`tests/integration/test_first_timer.gd` が同じ順で通す）。
- 出現地点の前（導入のポータルまでと、東へ歩く帯）には、置物・ブロック・ポータルを置かない。歩いて見回す案内が消えた後に、何も案内が残らない。
- 入口は台座と看板から、空色の渦が回るポータルに変わった。製品版の開き方では、まだ開いていないポータルは灰色で「まだ開いていない」、F を押すと「「○○」をクリアすると開きます」と出る。
- 草原の西・北東・南西に、能力を試せる小さな仕掛け（高台・鐘の扉・札の門）がある。導入より先に触っても詰まない（窪みのブロックは地面と同じ高さ、扉と門はただの寄り道）。試遊では、導入より先にこちらへ行ったかもメモする。

## 方針（本人の制約）

- 長い文章のチュートリアルや、操作を強いる手順は作らない。地形の配置と、必要になった瞬間だけ出て慣れたら消える短い案内（`HintMemory`、同じ操作を 3 回で消える）で教える。
- 自由な遊びを止めるシステムのルールは足さない。案内は「出す・消す」だけで、操作を止めたり順番を強制したりしない。
- 案内のキー表記は、最後に触った入力（キーボード／ゲームパッド）と、設定で割り当て直したキーに合わせる（`InputMode.key` / `InputMode.label`）。

伝えたい中心の考え:

1. 能力（W/A/S/D・ジャンプ・投げる…）は持ち物で、ブロック・地形・生き物・仲間に貸せる。
2. 禁止は能力より強い。
3. ルールは厳格、解き方は自由。

## 最初の 5 分で覚えること（監査）

「前」は 2026-11-20 の main（PR #45 時点）、「後」はこの変更の後。

| 覚えること | 前（どこで・どう教えていたか） | 後 |
|---|---|---|
| 歩く・カメラ | 教えていない（WASD とマウスは知っている前提） | 最初に照準の右下へ「[W/A/S/D] 歩く」「[マウス] 見回す」（パッドは左／右スティック）。3 秒ほど歩き、半周ほど見回すと消える |
| ハブでどこへ行くか | 出現地点の正面は 3〜4 番目の入口の間（みんなで回す・丘の上の旗）。導入は西へ 9m 先。到着時の知らせ「入口で F を押すとステージへ」と入口の看板だけ | 出現地点を西の端、導入の入口の真正面にした。導入の看板だけ「はじめはここから」を添える。入口に立つと「[F] 「跳ぶ力を貸す」へ」 |
| ホットバーの枠を選ぶ | 教えていない。選び替えたときに名前の吹き出しが出るだけ。最初は 1 番（W）が選ばれていて、案内は「[左クリック] 渡す」だけなので、W をブロックに渡しがち | ブロックを狙うと「[左クリック] Wを渡す」と選んでいる能力の名前が出て、並べて「[1〜9] えらぶ」（パッドは LB / RB）。5 を押すと「ジャンプを渡す」に変わる |
| 単発のジャンプをブロックに貸す | 手の届くブロックを狙うと「[左クリック] 渡す」「[右クリック] まとめて」が同時に出た（※依頼文の「右クリック／RT」は誤り。1 つに渡すのは左クリック／RT、右クリック／LT は範囲） | 「渡す」だけを先に出し、「まとめて」は 1 つずつ渡すのに 3 回慣れてから。足もとの地面を狙ったときは、初めのうちは渡す案内を出さない（地面にも渡せることは自分で気づく） |
| 貸した単発を Space で起動する | 教えていない | 単発で貸した能力があるあいだ「[Space] 貸したジャンプを使う」（パッドは A。W なら「貸したWを使う」）。どこを向いていても出る |
| F で回収 | 能力が付いたブロックを狙うと「[F] 回収」。ただし F を押せば何でも「回収した」と数えていたので、ハブの入口に 3 回入るだけで、回収を一度もせずに案内が消えた | 能力が付いたものを狙って F を押したときだけ数える（入口・鐘・拾うは数えない） |
| チェックポイント | 台座と看板「チェックポイント」、触れると知らせ「チーム共通になりました（台座で F: 全員復活）」。台座は道から 3.5m 横で、踏まずにクリアできた | 台座を出現地点からブロックへ向かう道の上（小段差の先、ブロックの 2.5m 手前）へ移した。初めての人も必ず踏んで知らせを見る |
| ゴールの窪みに集まる | 窪みの床に夕日色の薄い板、上に看板「ゴール（全員で集まる）」。板は下の地面からは窪みの縁に隠れて見えない | 窪みに、縁より高く立つオレンジの旗（「集まる」の紋）と四隅の光る柱を置く（3D モデルの PR #57 で、最初に入れた浮かぶ結晶から置き換えた。当たり判定なし）。看板はその上 |
| V 長押しの投票 | 投票が始まった後の知らせ「（V 長押しで賛成）」だけ。ひとりでは教えていない | ステージで目安の時間を過ぎたら「[V] 長押しでやり直し」（パッドは十字↓）。使うと消え、また目安の時間がたつまで出ない |
| Esc メニューからやり直す | 教えていない。**しかもゲーム本体では Esc を押してもメニューが開いた直後に閉じていた**（入力の係が開いた同じ Esc を、メニューが「閉じる」として受け取っていた） | 不具合を直した。上の V と一緒に「[Esc] メニュー」を出す |
| 禁止は能力より強い | 導入では出てこない。次の「鐘の谷」（全員ジャンプ禁止）とホットバーの禁止の印で知る | 変えていない（導入は「貸す」だけに絞る） |

### 照準の右下の案内が出る順番

```
広場:   [W/A/S/D] 歩く  [マウス] 見回す  →（慣れたら消える）
ポータル: [F] 「跳ぶ力を貸す」へ
導入:   （台座を踏む → 知らせ「チェックポイントがチーム共通に…」）
        ブロックを狙う → [左クリック] Wを渡す  [1〜9] えらぶ
        5 を押す      → [左クリック] ジャンプを渡す
        渡した後      → [F] 回収  [Space] 貸したジャンプを使う
        ブロックに乗って Space → ブロックが跳ぶ → 岩棚 → 窪み（旗の下）でクリア
迷ったとき（目安の時間を過ぎたら）: [V] 長押しでやり直し  [Esc] メニュー
```

自動テスト `tests/integration/test_first_timer.gd` が、この順番を初めての人と同じ操作で通す（入力はゲームと同じ `PlayerInput` を通す。入口・台座・ブロックの前へ行く道のりだけは置き直す）。ゲームパッドの表記と、ジャンプを J に割り当て直したときの表記も確かめる。

## 15 分の外部試遊チェックリスト

見守る人は口を出さない（聞かれたら「どう思う？」と返す）。詰まった場所と時刻だけメモする。

### 始める前

- [ ] 新しい記録の名前で始める（タイトルの記録の名前を `tester1` などにする）。慣れた案内の記録は名前ごとなので、前の人の記録が残らない
- [ ] 「ひとりで遊ぶ」から始めてもらう。説明は「15 分遊んでみて」だけ
- [ ] ゲームパッドの人とキーボードの人がいれば、両方で 1 回ずつ見たい

### 最初の 5 分（ハブ → 導入）

- [ ] 30 秒以内に歩き出し、カメラを回したか（「歩く／見回す」の案内が消えたか）
- [ ] 最初に入ったのは導入「跳ぶ力を貸す」か（ほかのポータルや広場の仕掛けに行ったなら、どこに惹かれたか）
- [ ] 入口で F（パッドは X）を押せたか。押すまでにかかった時間
- [ ] 導入で、自分では岩棚に跳べないことを試したか
- [ ] チェックポイントの台座を踏んで、知らせに気づいたか
- [ ] ブロックを狙ったとき、W を渡してしまったか（渡したなら、その後どうしたか。F で回収できたか）
- [ ] 5（パッドは LB / RB）でジャンプを選べたか
- [ ] ジャンプをブロックに渡せたか。渡した後に Space で「ブロックが跳ぶ」と分かったか
- [ ] ブロックに乗って跳び、岩棚へ移れたか（タイミングに何回失敗したか）
- [ ] 窪みの旗をゴールだと分かったか。クリアまでの時間（目安 3 分）
- [ ] 案内の文を声に出して読んだ・読まずに進んだ、のどちらか

### 残りの 10 分（ほかのステージ）

- [ ] 2 つ目の入口を自分で選べたか（どれを選んだか）
- [ ] 「鐘の谷」で、禁止（全員ジャンプ禁止）に気づいたか。禁止が能力より強いと分かったか
- [ ] 「繰り返し」（Q）や範囲（右クリック）を自分で見つけたか
- [ ] 想定と違う解き方をしたか（したなら、その方法。ルールで止めずに残すかは本人が決める）
- [ ] 詰まったとき、V 長押しか Esc メニューでやり直せたか（「やり直し」の案内が出たか）
- [ ] 落ちたとき、自動で戻ることに戸惑わなかったか

### 終わった後に聞くこと

- [ ] 「このゲームで、能力ってどういうもの？」——「物に貸せる」「取り返せる」が出るか
- [ ] 「いちばん分かりにくかった所は？」
- [ ] 「画面の文字は邪魔だった？足りなかった？」
- [ ] 案内が消えた後に、操作を忘れて困った場面があったか

## まだ確かめていないこと

- 人による試遊はまだ（このチェックリストで行う）。案内の出る位置・大きさ・消えるまでの回数（3 回）は、試遊の結果で調整する
- 「歩く」は 1 秒歩くごと、「見回す」は約 46° 回すごとに 1 回と数える（`PlayerInput.WALK_SECONDS_PER_USE` / `LOOK_RADIANS_PER_USE`、仮値）
- やり直しの案内を出すまでの時間は、ステージの目安時間そのまま（導入は 3 分。仮）
- 3D の看板（入口・台座）のキー表記は、島を作ったときの割り当てで描く。割り当て直したら次の島から変わる（照準の右下の案内はすぐ変わる）
