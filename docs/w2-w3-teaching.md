## 3. 案内の決まり（`src/ui/teach_hints.gd` に足したもの）

- 選ぶ順（上ほど急ぐ）に、**レバー**（鐘の次）と**発射台に投げるをえらぶ**（ステージの教える場所の次、渡すの前）を足した。
  ほかは W1 のまま。出すのはいつも 1 つ。
- 新しい記録の名前。どれも押したキーでは数えにくいので、案内を選ぶたびに**状態から**数える（`_learn_w2_w3`）。
  `PlayerInput` は変えていない。

| 記録 | 数えるとき |
|---|---|
| `launcher` | 自分の「投げる」が付いた発射台がある（1 回で慣れる） |
| `signal` | 信号の能力の付いたブロックが、鐘（板・レバー）の音を受けている（1 回で慣れる） |
| `dash` | ダッシュが始まった（始まった瞬間を 1 回と数える。3 回で慣れる） |
| `wind` | 風の中で足が床から離れている（1 回で慣れる） |
| `lever` | レバーの向きが変わった（1 回で慣れる） |

- ステージの教える場所（`StageDef.HintSpot`）のキーの表記に「→」を書くと、2 つのキーを続けて押す案内になる
  （"Space→Shift"。どちらも今の割り当て・パッドの表記に置きかえる）。key が `dash` の場所は、ダッシュを手元に持っていて
  使える（W/A/D のどれかがある）ときだけ出す。
- 遠くの**鐘**を狙ったときは「[C] 投げるで届く」を出さない（鐘は投げても鳴らない。発射台か生き物の木の実で鳴らす）。
- 鐘を狙うと毎フレーム SCRIPT ERROR になっていた（鐘は光らせる見た目を持たないのに `set_highlight` を呼んでいた）。
  `GameWorld.update_highlight` で、光らせられる物だけ光らせるようにした（通しで見つけた。案内の外の 2 行）。

## 4. ステージの形で変えたこと

| ステージ | 変えたこと | 理由 |
|---|---|---|
| 2-2 こだまの鐘 | 教える場所「乗ったまま鐘を鳴らす」（青い台 1 のそば、台に信号のジャンプがある間だけ） | 信号の初出なのに案内が無かった |
| 2-3 三つの鐘の島 | 原っぱのダッシュを外した | ダッシュを教えるのは 3-1。どの道にも要らないのに説明の無いまま拾えた。東の小島（幅 4）はブーツと発射台で渡れる |
| 2-6 風の尾根 | 浜のダッシュを外し、西の小島の谷を 4 → 3 にした（ブーツの場所も 1 マス東へ） | 同上。ブーツの道（道 3）は、前は「ダッシュで谷 4 を越えてブーツ」だった。谷 3 は走って跳べば届くので、道の数は変わらない |
| 3-1 ダッシュの浜 | 教える場所「跳んでからダッシュ」を 3 か所（浜の北の縁・小島の東の縁・東の崖の縁） | ダッシュの初出なのに案内が無かった |
| 3-4 風の通り道 | 教える場所「風が吹いたら跳ぶ」（追い風の空の手前） | 風の初出なのに案内が無かった |

2-1・2-4・2-5・3-2・3-3・3-5・3-6 の形は変えていない（2-5 の時の鐘の形は本人の決定どおり）。W1 と W4 以降は触っていない。
1-5 にはダッシュが落ちたまま（受け入れた技のテストが使う。W1 は今回の範囲の外）。

## 5. 足りない点・本人に聞きたいこと

- **信号（2-2）は「その方法しか無い」にはできなかった**。ジャンプを持てる島なので、石は単発の S で手で押せ、地面のセルの
  持ち上げ台（受け入れた技）でも上がれる。W1 の繰り返し（4）と同じく、「いちばん分かりやすい道に置いて見せる」までにした。
  必ず要るのは、2-1 の発射台・2-5 の時の鐘（谷 10）・3-1 のダッシュ・3-2 の往復足場・3-4 の風（ほかの道は横風の橋）。
- **真ん中（2-3・3-3）は「長い」が「難しい」ではない**。どの鐘も、知っている道具を 1 回使うだけで鳴る（東の鐘は 2-1 と同じ
  発射台）。最後（2-6）も、地面のセル（1-4）を 3 回押すだけの道がある。3-6 はジャンプの無い島での組み合わせで、難しい。
  形を変えると道が減る（本人は「道は何通りも」が好み）ので、今回は変えていない。案は報告書の「本人に決めてほしいこと」。
- 3-6 で初めて「生き物にグローブ（登る）を渡す」が要る（W4 の 4-2 で主役になる）。最後の難しいステージの組み合わせとして残した。
- 3-6 の「地上のダッシュ」（跳ばずにダッシュ）は 3-1 で教えていない（3-1 は空中ダッシュ）。港の鐘の往復足場の道もあるので残した。
- 人の速さの通しで、狙いにくい所が 2 つ見つかった（報告書の F12・F18）: 3-1 で砂丘の上の動物からジャンプを取り戻すとき、
  3-6 で高い岩の上の動物へ「投げる」を投げ渡すとき。どちらも見上げの上限（30 度）の近くで、狙える向きが少ない。
  形を変えるかは本人の判断（人の試遊でも確かめる）。
- 数値（案内の円の半径）はすべて仮。
