# 3D アートの方向（ゆるふわの箱庭）

状態: 提案（2026-11-18）。世界観・物語は未確定のため、ここでは**見た目のトーン**だけを決める。

## 方針

- UI（`src/ui/ui_theme.gd`）と同じ色の系統にそろえる。生成り・はちみつ・葉っぱの緑・空色。
- 角は丸める（面取りを大きく・段数を多く）。とがった岩や金属の部品は使わない。
- 彩度は中くらい。真っ白と真っ黒を避け、影も暖かくする。
- 禁止・範囲の赤は UI の `BAN` に寄せた柔らかい赤にする（色だけに頼らず、縁の線と札でも示す）。

納品の条件: GLB、1 万三角形前後、PBR テクスチャ 1024px、A ポーズ（リグがあれば付ける）、身長 1.4m 前後。

## 2026-11-19 地形を「ブロックなのに角張って見えない」形に（本人の要望）

本人の要望: ブロックでできた箱庭のゲームでも、見た目はそんなに四角く見えないものが多い。そうしたい。

- セルごとに角を丸めた箱を並べるのをやめ、島の地形を **1つにつないだモデル** にした（`art/scripts/build_terrain.py`）。
  外に出ている面だけを作るので、内側の継ぎ目は消える。折れ曲がった辺は凸も凹も丸める（0.13）
- ブロックでできていることは残す: 岩・砂岩の側面はセルごとに少し膨らませて石積みに、色はセルごとにわずかに変える
- 側面の頂点だけを少し揺らし、定規で引いた直線を崩す。上面は歩く面なので揺らさない
- 当たり判定は箱のまま（見た目と1〜3cm ずれる）。動くブロック（能力を受け取るブロック）は対象外
- 地形を変えたら `godot --headless --script res://tools/export_terrain.gd` → `blender -b --factory-startup --python art/scripts/build_terrain.py`。
  作り直し忘れはテスト（`test_terrain_layout`）で分かる

画面: `docs/images/compare/soft-terrain-after.png`（前は `cozy-art-after.png`）。

### 2026-11-19 追記: 地形の見た目を実行時に作る方式へ

どのブロックにも渡せるようにした（地形のセルが動くブロックになって抜ける）ため、地形の見た目を Blender で作り置きするのをやめ、
ゲームの中で作り直す（`src/game/terrain_mesher.gd`）。外に出た面だけを作り、凸の角を半径 0.16 で丸める考え方は同じ。
色は頂点の色で、草のセルは上面と上の縁から少し下まで草色、セルごとにわずかに色を変える。岩の石積み風の膨らみは、まだ移していない。

## 2026-11-19 発射台と鐘（本人の要望: ひと目で分かるように、テクスチャまでこだわる）

## 2026-11-20 モデルの第2弾（本人の要望: 「3D モデルも頑張れそうやったら頑張って作ってほしい」）

本人が決めた方向: ゆるふわで温かみのある3Dブロックの箱庭。子どもっぽくしすぎず、製品版らしい仕上がり。
既存作品の模倣はしない。世界観は未定（`docs/worldview/` で別に検討中）なので、形と色の系統だけをそろえ、
特定の設定を示す飾りは付けない。当たり判定は箱（または無し）のままで、モデルは見た目だけ。

作り方の約束（AI の判断。理由も残す）:
- 色は `art/scripts/palette.py` の定数だけから取る。世界観が決まったら、ここを直して実行し直せば塗り直せる。
- 丸い形は共通の部品（回転体・カプセル・輪・角丸の箱）で作る。生の立方体は使わない。
- 役割は色と形の両方で示す（色だけに頼らない）。ゴール＝夕日色の旗と「集まる」印、チェックポイント＝若葉の灯り、
  入口＝空色の門、能力＝はちみつ色のメダル、禁止＝灰の地に赤い輪と斜線。
- 顔は目と頬だけ（口は描かない）。目は小さめにして、幼くなりすぎないようにした。

## 2026-11-21 広場（オーバーワールド）と骨格のアニメーション

本人の決定: 「ゆるふわで温かみのある3Dブロックの箱庭」。明るい昼・丸くてかわいい生き物・やさしい世界。参考にした作品からは何も写さない。
動くものは部品ごとに作り、骨格（Rig）とアニメーションで動かす。

| 部品 | 前 | 後 |
|---|---|---|
| プレイヤー | 関節をコードで振る | 骨格付き。idle（息をする）・walk（脚と腕を振り、胴が弾む）・jump（脚をたたみ腕を横へ）・happy（跳ねて両腕を振る） |
| 願いを持つ生き物・子ども | 体を上下させるだけ | 部品（からだ・羽・足・芽）を骨格で。idle（ふくらむ・芽が揺れる）・walk（よちよち）・happy（跳ねて羽ばたく） |
| 広場の生き物 | なし | 耳の長い生き物（耳・しっぽ・足）、もこもこの生き物（毛の玉のからだ・4本脚）。どちらも idle・walk・happy |
| 入口 | 台座と吊り札の門 | ワープの門: 石と葉のアーチ・空色の渦（回る）・クリアの金色の花。閉じた門は灰色で止まる |
| 広場の発展 | 報酬の名前を文字で出すだけ | クリアごとに建物（家・風車・噴水・畑・見晴らし台・屋台）と、生き物が住む |
| 広場の地形 | 平らな芝生の長方形 | 楕円の浮島をつないだ箱庭。上面は草、高い所の側面は石の崖、下に浮かぶ島の底。地方ごとに置物を変える（草原は花、森は木、庭は鉢植え、峰は小石） |
