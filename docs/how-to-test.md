# テストのしかた（ひとり・2人以上・ホスト移譲）

2026-11-20 時点のマルチプレイ（PR #25〜#30）を、本人が通しで試すための手順。
ここに書いた操作は、自動テスト（`tools/check.sh`）で同じ流れを確かめてある。ただし、別々の PC 同士・インターネット越し・Windows 11 実機ではまだ試していない。

## 0. 実行ファイルを手に入れる

どちらか一方でよい。

**A0. Release から落とす（いちばん簡単）**
- `v0.1.0` のようなタグを push すると、GitHub の「Releases」に配布用の ZIP が並ぶ。
  - `rule-relay-v0.1.0-windows.zip`
  - `rule-relay-v0.1.0-macos.zip`（署名・公証済み。警告なしで開ける）
  - `rule-relay-v0.1.0-linux.zip`（Linux・Steam Deck 用。展開して `rule-relay.x86_64` を起動）
- タグの付け方:
  - GitHub の「Releases」→「Draft a new release」→「Choose a tag」に新しいタグ名を入れて公開すると、少しして ZIP が自動で付く（この画面で ZIP を付ける必要はない）。
  - またはターミナルで次を実行する。

    ```bash
    git tag v0.1.0
    ```

    ```bash
    git push origin v0.1.0
    ```

**A. CI が作った実行ファイルを使う（おすすめ）**
1. GitHub の Actions で main の最新の「CI」を開き、一番下の「Artifacts」から落とす。
   - Windows は `rule-relay-windows`、Mac は `rule-relay-macos`。
2. Windows: ZIP を展開して `rule-relay.exe` を起動する。
3. Mac: 落とした ZIP の中の `rule-relay.zip` を展開して `.app` を起動する。
   - Intel と Apple シリコンの両方で動く。
   - 署名と公証を済ませた版（`rule-relay-macos-signed`。`docs/macos-signing.md` の Secrets を登録すると CI が作る）なら、警告なしで開ける。
   - 署名なしの `rule-relay-macos` では、最初は「開発元を確認できません」と出る。
   - その場合は、アプリを右クリック →「開く」。またはシステム設定 →「プライバシーとセキュリティ」→「このまま開く」。
   - それでも開けないときは、ターミナルで次を実行する。

     ```bash
     xattr -dr com.apple.quarantine "rule-relay (working title).app"
     ```

   - 部屋を作ると「受信接続を許可しますか」と聞かれるので、「許可」を押す（Windows でも同様にファイアウォールの許可が出る）。

**B. Godot エディタで開く**
1. Godot 4.6.3（標準版）でこのフォルダの `project.godot` を開く。
2. F5 で起動する。

## 1. ひとりで遊ぶ

1. タイトルで「ひとりで遊ぶ」を押す。
2. ハブ（広場）に出る。入口（台座と看板）が、目安のクリア時間の短い順に西から東へ並んでいる。出現地点は西の端で、正面が最初の入口（導入）。初めての人への案内の流れは `docs/onboarding.md`。上に立って **F** を押すとステージに入る。クリアすると「実際の時間（目安 N 分）」が出るので、順番に試して感想を教えてほしい。
   - 跳ぶ力を貸す（3分）→ 鐘の谷（4分）→ みんなで回す（5分）→ 丘の上の旗（8分）→ 採石場（12分）→ 三つの鐘の島（20分）→ 浮島めぐり（30分）。分数はすべて仮。
   - どの島も壁で区切っていない開けた島で、ゴールへの道は何通りもある（ブロックに能力を貸す・落ちている装備やダッシュを探す・発射台・協力で能力を集める）。
   - 「三つの鐘の島」「浮島めぐり」は鐘を3つ全部鳴らすとクリア。協力なら手分けできる。
   - ダッシュ（Shift / ゲームパッドの B）: 方向キー（W/A/D）を押しながらで、その向きへまっすぐ 3 マス突進し、途中の穴は落ちずに抜ける。W/A/D のどれも持っていないと使えない。床に着くまで1回。島のどこかに落ちている。
   - 「跳ぶ力を貸す」（導入）
   - 「みんなで回す」
   - 「鐘の谷」
3. 「跳ぶ力を貸す」の解き方の一例:
   1. 岩棚は自分では跳べない。
   2. 手前の窪みにあるブロックに、ジャンプを渡す（ホットバー 5 を選ぶ → 左クリック。Q で「繰り返し」にすると楽）。
   3. ブロックに乗ると持ち上げられるので、岩棚に移る。
4. 確かめること:
   - **落ちる**: 自動でステージの最初か、チェックポイントからやり直しになる。ひとりでは観戦のまま止まらない。
   - **チェックポイント**: 台座に触れると「チーム共通」になる。そのあと落ちると、そこから再開する。
   - **V 長押し（約 0.8 秒）**: 全員リセットの投票（短く押しただけでは投票しない）。ひとりなら自分の1票ですぐ成立する。Esc メニューの「もどる」も同じ。
   - **クリア**: 報酬（仮の名前）が表示され、4秒ほどでハブへ戻る。2回目のクリアでは初回報酬は出ない。

## 1.5 設定（キー割り当て・文字の大きさ・視点の速さ・音の大きさ）

1. ゲーム中に **Esc**（ゲームパッドは **Start**）でメニューを開き、「せってい」を選ぶ。
2. できること（変えるとすぐ反映し、`user://settings.cfg` に保存する。次に起動したときも同じ設定で始まる）:
   - **文字の大きさ**: 小さめ／ふつう／大きめ／とても大きい（画面全体の UI の拡大率。持ち物の画面は、はみ出すときだけ収まるように縮む）。
   - **視点の速さ**: マウスとパッド（右スティック）を別々に ×0.3〜×3.0。
   - **音の大きさ**: 「BGM の音量」と「効果音の音量」を別々に 0〜100%（5% きざみ。初期値は BGM 70%・効果音 100%）。
     動かすとすぐ変わる。効果音のつまみは、動かすたびに選んだ音が鳴るので大きさを確かめられる。0% で消音。
     保存はメニューを閉じたとき。パッドでは十字キーの上下でつまみへ移り、左右で動かす。
   - **キー割り当て**: 前・後ろ・左・右・ジャンプ・突進・回収（F）・渡す・全員リセットの投票（長押しのまま）・持ち物・メニュー。
     キーボード・マウスの列とゲームパッドの列があり、ボタンを選んでから割り当てたい入力を押す（5秒押さなければ取り消し）。
     - ほかの主な操作が使っている入力を選ぶと、2つの操作の割り当てを入れかえる（どちらも空にならない）。
     - Q・C・X・1〜9・右クリック・ホイールなど、ここで変えられない操作が使っている入力は断って、理由を出す。
     - 照準の下の案内（[F] 回収 など）や知らせの文も、割り当て直したキーで出る。
   - **はじめの設定にもどす**: もう一度選ぶと確定（文字の大きさ・視点の速さ・音の大きさ・キー割り当てをすべて初期値に）。
3. ゲームパッドだけで操作できる: 十字キーで項目を移り、A で決定、つまみは左右で動かす。**B** か **Start** でメニューへもどる。
4. 設定ファイルの場所（消すと初期値にもどる）: Windows は `%APPDATA%\Godot\app_userdata\rule-relay (working title)\settings.cfg`、
   Linux は `~/.local/share/godot/app_userdata/rule-relay (working title)/settings.cfg`。
   操作の案内の「慣れた」記録も、記録の名前ごとに同じ場所の `hints/<記録の名前>.json` に残る（消すと案内がまた出る）。

### BGM を聴いて確かめる

- タイトル → ハブ → 島 → ハブ で曲が変わり、約1.5秒で前の曲と重なりながら入れ替わる。
- 島で「島のはじめから」や全員リセットをしても、曲は頭に戻らずに続く。
- Esc のメニュー・せってい・持ち物（E）を開いている間は、曲が少し（−6dB）下がる。閉じると戻る。
- 曲の継ぎ目（ハブ約106秒・島約84秒・タイトル約37秒ごと）でぷつっと切れたり間が空いたりしないか。
- 曲は仮の選曲（`docs/sound-design.md` の「BGM」）。差し替えたい曲があれば候補の ID（B2 など）で伝える。

## 2. 2人以上で遊ぶ（同じ PC で2つ起動して試せる）

**Mac と Windows で一緒に遊べる**: どちらがホストでも、Mac と Windows の組み合わせでつながる（同じ通信方式。ゲームの版はそろえる）。

**同じ PC で試す**
1. 1つ目を起動する。記録の名前を `player` のまま「部屋を作る」。ポートは 24565。
2. 2つ目を起動する。記録の名前を `player2` などに変え、IP アドレス `127.0.0.1`・ポート 24565 で「部屋に入る」。
3. コマンドラインでも起動できる（ターミナルから）。
   - 1つ目（ホスト）:

     ```bash
     rule-relay.exe -- --host --profile=player
     ```

   - 2つ目（参加者）:

     ```bash
     rule-relay.exe -- --join=127.0.0.1 --profile=player2
     ```

   - Mac は、`.app` の中の実行ファイルに同じ引数を付ける。

     ```bash
     "rule-relay (working title).app/Contents/MacOS/rule-relay (working title)" -- --host --profile=player
     ```

**別の PC の友だちと遊ぶ**
- 同じ Wi-Fi（LAN）なら、ホストの PC の IP アドレス（例 `192.168.x.x`）を入れて「部屋に入る」。
- インターネット越しの場合、ホスト側のルーターで UDP 24565 のポート開放が必要。Steam 版にすれば不要になる。

**確かめること**
- **お互いが見える・ブロックが同じ動きをする**。
- **仲間へ能力を渡す**: 仲間を狙って左クリック。承認はいらない。
  - 渡した人の器は残るが、効かなくなる。
  - 受け取った人は ×n になる。
- **F 回収**: 仲間がブロックに貸した能力を自分が F で回収すると、自分のものになる（元の人には戻らない）。
- **単発の返還**: 仲間からもらった能力を単発でブロックに渡す → キーで発動 → 自分（直前に貸した人）に戻る。
- **死亡観戦**: 落ちると観戦になり、生きている仲間の画面を映す。
  - 生きている人が台座で **F** を押すと、その場で全員復活（世界は巻き戻らない）。
  - 全員が落ちると、自動でチェックポイントからやり直し。
- **全員リセット（V）**: 過半数で成立する（2人なら2票、3人なら2票、4人なら3票）。世界ごと戻る。
  - **投票には時間切れがある（仮 30 秒）**。投票が開いている間、上の札に「全員リセットの投票 1 / 2（V 長押しで賛成・残り 24 秒）」のように残り秒数が出る。後から入った票では延びない。
  - 30 秒たつと「全員リセットの投票は時間切れになりました」と出て、全員の札から投票が消える。前の票は数えられなくなり、次の V 長押しで新しい投票が始まる。
  - 確かめること: 1人だけ V を押して 30 秒待つ → 時間切れになる → そのあと仲間が落ちても、世界は戻らない（落ちた人は台座の F で復活できる）。
  - ホスト移譲をはさんでも、残り秒数は引き継がれる。
- **ゴールにまだ来ていない人**: 協力中、誰かがゴールに入るか、島の条件（鐘・運ぶ物など）がそろうと、札の2行目に「ゴールにまだ来ていない: プレイヤー2」のように、ゴールに入っていない生きている人の名前が出る（自分は「あなた」）。知らせるだけで、外したり止めたりはしない。ひとりのときとクリアした後は出ない。
- **途中参加**: ステージ中に入った人は観戦になり、次の全員リセットで合流する。
- **クリア**: 参加していた人全員に報酬が入り、各自の PC に保存される。
  - 死亡観戦中の人も、通信が切れていて部屋があるうちに戻った人も受け取れる。
  - クリア前に自分で抜けた人は受け取れない。
- **再接続**: 参加者がアプリを閉じて同じ「記録の名前」で入り直すと、同じプレイヤーに戻る（持っていた能力もそのまま）。

## 3. ホスト移譲を試す（3つ起動する）

1. ホスト・参加者 B・参加者 C の3つを起動して、同じ部屋に入る。
2. B でブロックに能力を貸しておく。
3. ホストのウィンドウを閉じる。
4. 確かめること:
   - B と C の画面が止まり、「ホスト選出中…」と出る。
   - B に「あなたがホストになりました」と出る。
   - C は B につなぎ直す。
   - B が貸していた能力・ステージ・チームの状態が続いている。
   - 前のホストは「通信が切れた人」になる。同じ記録の名前で入り直せば、同じプレイヤーに戻る。
5. 限界（いまの作り）:
   - 新しいホストは、前のホストと同じポートで部屋を開き直す。別の PC 同士では、新しいホストの PC にもポート開放が必要。
   - 参加者が1人だけ（ホストと2人）だと、引き継ぐ相手がいないので「ホストが見つかりません」と出て終わる（成功したふりはしない）。

## ゲームパッドで遊ぶ（Xbox 風の並び。Steam Deck も同じ）

| ボタン | 動作 | キーボードでは |
|---|---|---|
| 左スティック | 移動 | W/A/S/D |
| 右スティック | カメラ | マウス |
| A | ジャンプ | Space |
| X | 回収・拾う・鐘・台座・入口 | F |
| Y | 触る ↔ 投げる | C |
| RT | 狙ったものに渡す | 左クリック |
| LT（押している間プレビュー、離すと渡す） | まとめて渡す | 右クリック |
| LB / RB | ホットバーの枠を選ぶ | 1〜9 |
| 十字↑ | 発動方式の切り替え | Q |
| 十字↓ 長押し | 全員リセットの投票（約 0.8 秒） | V 長押し |
| 右スティック押し込み＋右スティック | 円形メニューで方式を選ぶ | ホイール押し込み＋ドラッグ |
| View | 持ち物を開く・閉じる | E |
| Start | メニュー | Esc |

持ち物画面では、十字←→で持ち物を選び、LB/RB で入れる枠を選んで A でホットバーへ入れる。X でかばんへ戻し、Y で装備をつける・外す。

画面の操作案内は、最後に触ったのがゲームパッドかキーボードかで表記が切り替わる。
ボタンの割り当ては、メニューの「せってい」で変えられる（上の 1.5）。
