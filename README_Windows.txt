rule-relay（仮題）Windows 版の起動のしかた
==========================================

この ZIP の rule-relay.exe は、コード署名をしていません（有料の証明書を使っていないため）。
そのため Windows 11 では、初めて起動するときに次のどちらかの画面が出ることがあります。

■ 1.「Windows によって PC が保護されました」（SmartScreen）

  画面の「詳細情報」を押し、出てきた「実行」を押すと起動できます。

  別のやり方（ZIP を展開する前に）:
    ZIP ファイルを右クリック → 「プロパティ」→ 下の方の「許可する」にチェック → 「OK」。
    そのあと ZIP を展開すると、この画面が出なくなります。

■ 2.「スマート アプリ コントロールでブロックされました」（Smart App Control）

  スマート アプリ コントロールがオンの PC では、署名のないこのゲームは起動できません。
  この画面には「実行」のボタンがなく、上のやり方でも起動できません。

  設定の場所:
    設定 → プライバシーとセキュリティ → Windows セキュリティ
    → アプリとブラウザー コントロール → スマート アプリ コントロール

  注意: Windows の版によっては、スマート アプリ コントロールを一度オフにすると、
  Windows を入れ直さない限りオンに戻せません。オフにするかどうかは、ご自身で判断してください。

  オフにしない場合の代わりの方法:
    公式の Godot 4.6.3 エディター（godotengine.org から入手できます）で、
    このゲームのプロジェクト（ソース一式）を開いて実行できます。

■ 動きがカクつくとき

  タイトルか Esc のメニューの「せってい」→「画質」で「低」を選ぶと軽くなります（影を近くだけにし、
  描く解像度を下げます）。はじめは「中」です。

■ そのほか

  - 同梱の LICENSES.txt に、使っている部品のライセンスを載せています。
  - 遊び方と協力プレイのつなぎ方は、配布元のページの説明（docs/how-to-test.md）を見てください。
